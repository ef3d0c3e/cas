# cargo fmt inside fuzz/ reformats every target

- `fuzz/` is its own crate, not in the workspace: `cargo fmt --all --check` at the root does not cover it.
- Running `cargo fmt` inside `fuzz/` rewrites every `fuzz_targets/*.rs` (they were never formatted).
- Edit a fuzz target by hand and check it with `cargo check --all-targets` in `fuzz/`. If you ran fmt there by accident, `git checkout -- fuzz/fuzz_targets` the files you did not mean to touch.
