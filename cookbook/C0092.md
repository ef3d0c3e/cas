# Natives re-approximating symbolic arguments: check is_numeric first

Symptom: eval fuzz timeout growing ~2^depth on nested calls of one native (Fuzz 45608125834, 77 s;
`LowPass` with a cutoff holding further `LowPass` calls).
Mechanism: `numeric::approximation(ctx, …)` called from a native is a fresh `Context::eval`: full
recursion budget again, a new state id, so no memo hit. A native that approximates its already-evaluated
symbolic argument re-evaluates every nested call inside it, twice a level.
Fix: approximate only `x.is_numeric()` arguments, else `Ok(None)` (as rounding.rs:93, truncation.rs:125).
Rejected: approximating through `Eval::eval_in` (keeps the level budget) bounded the depth but still ran
past 120 s. About 55 native call sites of `numeric::approximation`: audit any that can nest in itself.
Regression: N nested calls (32) come back unchanged, signal/tests.rs `nested_filters_stay`.
