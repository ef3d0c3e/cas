# C0003 — Run CI's stable clippy locally (nightly is the default)
tags: clippy,toolchain,ci,lint · date: 2026-11-22 · phase/task: - · origin: gen3.2 memory ci-on-github.md

CI's clippy job runs the stable toolchain (`dtolnay/rust-toolchain@stable`); the local default is nightly with its bin
dir directly on PATH (no rustup proxies), so `cargo +stable clippy` and `rustup run stable cargo clippy` still run
nightly's clippy and miss lints stable flags (needless_range_loop broke CI 2026-10-28). To match CI:
`S=~/.rustup/toolchains/stable-x86_64-unknown-linux-gnu/bin; PATH=$S:$PATH CARGO_TARGET_DIR=target/stable cargo clippy -q -p <crate> --lib --tests -- -D warnings`
(clippy is a lint, not a test: allowed locally).
