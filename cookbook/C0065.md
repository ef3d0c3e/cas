# giac string order is byte order; Expr's Ord is not

`order.rs:246 cmp_names` folds case (`"a" < "A"`), so `Sort` via `Expr::cmp` and any ordering through `Expr`'s `Ord`
disagree with giac, which compares strings bytewise (`sort(["b","A","a","aa",""])` = `["","A","a","aa","b"]`,
`"B"<"a"` true; probe .run/1.6/T2/probe8.out).

- Compare two strings with Rust `str::cmp` (UTF-8 byte order = code point order), as `logic.rs order` and
  `lists.rs sort` do since 1.6/T2.c2 (sort refills only the string slots in byte order, keeping the order total).
- Never change `cmp_names` for this: it is the canonical order of names and symbols too.
