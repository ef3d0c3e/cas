# Porting giac code that mixes exact and float entries: Exact|Float per entry

giac's gen arithmetic keeps exact op exact exact; any operand that is a double makes the result a double.
A tableau or matrix routine fed one decimal therefore answers mixed entries (simplex_reduce: `[0.75,1,1/2,0,3/2]`).
- Prototype: Python's `fractions.Fraction`/`float` tower behaves the same (Fraction + float -> float); normalise
  integral Fractions to int for printing. .run/1.5/check/simplex_reduce.py matched 9/9 probes first try (1.5/T5).
- Rust: an `enum { Exact(Rational), Float(f64) }` per entry with that rule; decimals read by to_f64 (C0028),
  non-finite leaves the call; zero/one/sign tests as giac's is_zero/is_one/is_strictly_positive on either arm.
- Cheaper and closer than converting the whole input to floats or balls, which loses giac's exact columns.
