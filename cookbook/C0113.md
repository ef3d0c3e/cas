# giac string answers with `"` or `\` do not read back: compare through asc

giac prints a `"` inside a string doubled and a `\` bare (`"a\"b"` prints `"a""b"`); `ours()` cannot read that back. A sweep of string-valued commands (mid, left, right, trim, char, join) compares `asc(<call>)` instead. Inputs: a string ending in `\` reads as unclosed in giac's lexer (`size("a\\")` = undef): skip it.
