# Adding a session setting (the Digits precedent)

A setting (Digits, all_trig_solutions, with_sqrt) is session state, not a builtin's job: a native gets `&Context`
only (`Eval.context: &Context`, eval.rs:95), so it cannot set anything.

- State: a field in `context.rs` `State` with getter/setter beside `working_precision`; `state_mut()` gives a new
  state id, so cached results are not reused across the change.
- Name: a PROTECTED builtin (builtin.rs, after DIGITS) and an en.txt `[builtins]` line; its bare name reads the value
  in `native.rs` `value()`; a BUILTINS entry in fuzz/fuzz_targets/eval.rs.
- Assignment `name := v`: the lowering must let it through (`fn setting` in crates/cas-lang/src/lower.rs, widened from
  the `Digits :=` arm), else it lowers as an assignment to a protected builtin; then session.rs `assign` dispatches
  (`set_digits` / `set_flag`).
- Call form `name(v)` (giac's for with_sqrt, which refuses `with_sqrt:=`): an execute arm in session.rs.
- Oracle tests: giac's instance is shared per test binary, so each setting's test is its own tests/*.rs file, setting
  and resetting the flag inside one giac input and taking the last value of giac's sequence; ours runs in a
  `cas_lang::Session` with the flag set (tests/all_trig_solutions.rs, tests/with_sqrt.rs).
