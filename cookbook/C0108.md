# giac's hht spectrum bins: top edge in bin fbins-2; a +-0 imaginary part flips inst_freq

Found at 1.8/T6 (T6.c2, CAS-648; probes crates/cas-core/proto/wavelet/giac/p7.cas end rows).
- giac's hht (signalprocessing.cc:5424) bins `floor((fbins-1)*(f-fmin)/r)`, yet a frequency exactly at the range top
  (f-fmin == r) lands in bin fbins-2, never fbins-1; exact interior integers keep their bin. No f64 operation order
  reproduces it: copy the observed behaviour and document it (hht.rs).
- inst_freq is `max(0, arg(conj(z[k-1])*z[k]))`: an imaginary part near 0 decides pi vs 0. giac's dht gives exact
  zeros there (arg = pi); treat a ball containing 0 as +0. A Python prototype on numpy FFT noise gets
  `hht([[1,-1,1,-1]])` wrong: prototype noise-free.
