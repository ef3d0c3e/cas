# eval SIGSEGV with no artifact: replay the cached corpus on CI; bound native recursion with ev.enter()

A stack overflow on eval's evaluation thread kills the process with SIGSEGV and no artifact; the corpus lives only
in the Actions cache. Seen 1.8/T5 (Fuzz 45768024104; crash introduced by T4's Period, CAS-640).
- Locate: `gh workflow run fuzz.yml -f targets=eval -f replay=true` replays the restored corpus once in batches
  of 500; grep `REPLAY` in the job log (`REPLAY CRASH <file>`, `REPLAY BASE64 <b64>`); the file is also in the
  run's `fuzz-artifacts-eval-<run>` artifact. A dispatch cancels the running push Fuzz run (shared concurrency).
- Decode with the run's own eval.rs (C0093, C0005 scratch crate); gdb names the self-calling frame (C0002).
- Cause pattern: a native recursing in its own Rust code (here `periodic` into an unevaluated `Together[...]`,
  read as a one-argument function whose argument is itself) is not bounded by the evaluator's levels. Take a
  level per Rust recursion (`ev.enter()`/`ev.leave()`, body in a `_in` helper) so cycles end in RecursionLimit,
  and read helper heads left unevaluated (`Together`, `Expand`) as their argument.
- A fuzz run that ends in a cancel says nothing: check the last *completed* eval job before closing a task.
