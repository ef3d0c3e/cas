# C — Ported natives that index arguments: guard kernel arity at the entry

The eval fuzzer builds calls of any arity (`Exp[]`, `Power[x]`, `ArcTan[x,x]`); an argument-free `Exp[]` stays
unevaluated and reaches natives inside the integrand. A port of giac/C++ code that reads `k.args()[0]` panics
(index out of bounds; Risch, risch.rs:457, Fuzz run 45172144522).

Move: one `malformed(&f)` check at the native's entry (walk `f.distinct()`, test each kernel head's arity:
Exp/ArcTan/Sin/Cos != 1, Log == 0, Power != 2) and return `Ok(None)`; one unit test with each bad kernel inside
`x * k`. Cheaper and safer than guarding every index site (Risch had seven).
Source: 1.3/T11, commit 66e0c9e (crates/cas-core/src/native/integrate/risch.rs `malformed`).
