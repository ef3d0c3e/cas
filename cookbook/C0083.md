# Together leaves balls untouched: test for a ball before wrapping a numeric result

`Together` (and the polynomial natives) accept exact data only: `Together[Ball]` stays as a call. A helper that wraps
a quotient in `Together` (regression.rs `line`, slope sxy/sxx) leaves `Together[Ball]` on decimal data; `real_sign`
then answers None (a sign test takes a wrong branch) and `N[…]` never reduces it (oracle `Less` checks never True).
Move: evaluate first; wrap in `Together` only when the result is not `View::Ball`.
Origin: T3.c3 CAS-627 (logistic_regression decimal rows answered Indeterminate; CI 45584193534).
