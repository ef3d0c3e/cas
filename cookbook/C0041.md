# Zero-testing exp expressions: exponent atoms to fresh symbols, then Together

From 1.3/T9.c6 (CAS-585, 2026-11-23, crates/cas-core/src/native/integrate/risch.rs `vanishes`, `exp_generators`).
- Plain evaluation never merges `Exp[1]*Exp[x-1]` (nor E^u with Exp[u], C0036), and Together treats each Exp as
  its own kernel, so a correct antiderivative such as exp(1)*Ei(x-1) fails a D(F) - f = 0 check.
- Sound test: write E^u, E and numeric a^u as Exp; expand each exponent into atoms t with rational coefficients q;
  map Exp[Σ q t] to Π z_t^(q L_t) with fresh symbols z_t = Exp[t/L_t] (L_t the lcm of t's denominators); Together
  of the image is 0 ⇒ the original is 0 (the map is a homomorphism from the free algebra). It can only reject a
  true zero (missed relations like exp(ln x) = x), never accept a non-zero difference.
- Keep the cheaper tests first (Together; TrigToExp + TranscendentalSimplify), this as the third.
