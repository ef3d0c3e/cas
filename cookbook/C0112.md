# Sweeping a giac predicate: build only the true case

Problem: a sweep of `type(r)==DOM_X` with a random DOM_X fails when the pair is false: giac answers `false`, ours leaves `DOM_RAT == DOM_INT` unevaluated (`==` of two distinct symbols stays symbolic here).
Fix: generate the input so the comparison is true (compare each value with its own DOM_), or compare the bare value (`type(r)`) instead of the predicate.
Also from T8.c2 (giac probes, caseval): `trunc(x,n)` with n<0 counts significant digits through doubles (`trunc(150,-2)` = 140.0, `trunc(0,-1)` errors): sweep n ≥ 0 only; `bernoulli_mod(n,2)` crashes libgiac; `icomp(n,k,zeros=true)` with k>n errors.
