# Kovacic port: ODE rows for a quoted giac builtin, algebraic poles, linear systems by monomials

From 1.3/T8.c2 (CAS-584, 2026-11-23, crates/cas-core/src/native/dsolve/kovacic.rs).
- giac builtins with `_QUOTE_ARGUMENTS` (kovacicsols) answer Bad Argument Value to `diff(y(x),x,x)` equations and
  our language has no `y''`: oracle agreement rows use the `[a,b,c]` list form (no `/` in it, C0037); the equation
  forms are departure rows plus unit tests.
- `Together` does not cancel a factor at an algebraic root (x-sqrt 2, x-I): for `r*(x-c)^m` divide the quadratic
  factor by the other root's linear factor first.
- Undetermined-coefficient systems (P monic of degree d): apply the operator to each monomial x^i and read the
  coefficient matrix, instead of symbolic unknowns and Solve; bound d^3 and d^2 x equations by `Limits::terms` (C0019).
- Answers with exponentials: emit `Exp[u]`, not `E^u`, so giac's `exp(...)` reads back equal (C0036).
