# C0004 — gh API rate limit: one slow watcher per run
tags: gh,ci,rate-limit,watch · date: 2026-11-22 · phase/task: - · origin: gen3.2 memory ci-on-github.md

GitHub API quota is 5000 requests/h. `gh run watch` polls every 3 s by default: two watchers over a ~25 min CI + fuzz
cycle, several times an hour, exhausted it on 2026-10-25 (HTTP 403 "API rate limit exceeded"; `gh api rate_limit`
shows the reset and does not count). One watcher per run, `gh run watch <id> --interval 60 --exit-status` as a
background shell; its completion notice wakes you. Never a hand-written sleep loop.
