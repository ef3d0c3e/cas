# Porting a float iteration to rounded Rationals: round every repeated factor

Context: giac's newton (solve.cc:5919) runs in doubles; our port (crates/cas-core/src/native/solve/newton.rs, T3.c3, CAS-591, 2026-11-23) runs on Rationals rounded to working precision + 32 bits (fsolve.rs `rounded`, `at`).
- Rounding the iterates alone is not enough: a damping factor updated by `lambda *= 6/5` / `lambda /= 2` grows a 5^k denominator; round it after each update too.
- Map giac's float edge cases explicitly: f' = 0 with f != 0 is giac's infinite step (first loop ends as if exhausted); 0/0 or missing f' restarts in-loop; f(b) not real halves lambda.
- Prototype first in Python with the same control flow (C0009); the Rust port copies it step for step.
