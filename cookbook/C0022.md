# C0022 — Stays-unevaluated tests: write the input in canonical orderless order
tags: test,unevaluated,orderless,cas-core · date: 2026-11-23 · phase/task: 1.3/T2 · origin: CAS-548 chrem stays row

- ORDERLESS heads (Plus, Times) are sorted on eval: Plus[Power[x,2],1] comes back Plus[1,Power[x,2]] and the test fails
  though the native returned None. Write such inputs in canonical order, or compare against eval of the arguments.
