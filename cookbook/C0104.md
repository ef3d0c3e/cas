# giac's doubles have their low 5 mantissa bits cleared: ports that count with doubles must too

giac rounds doubles off (gen.cc `print_DOUBLE_`, and in values: `evalf(1/3)*3-1` = -3.55e-15, not the IEEE answer).
Seen 1.8/T5: `range(0,1,1/3)` has 4 elements and `range(0,1,0.1)` 11, because the stepping runs on giac's roundoff
doubles. A port that counts or compares with doubles reproduces giac only with the same mask (clear the low 5
mantissa bits after each operation); prove it on caseval rows with a non-binary step before writing the Rust.

Related unit-test trap (C0098): full-form test strings write rationals `3/5`, never `Rational[3, 5]` (that stays a
call, not a number); "stays" inputs must be canonical (`Plus[1, Power[x, 2]]`).
