# Oracle rows for a builtin that returns a sequence: bracket the input

Found at T3.c1 (2026-11-23, makesuite/CAS-557).
- giac prints a sequence bare (`makesuite([1,2,3])` => `1,2,3`); our language cannot read a bare `1,2,3`, so
  `ours()` on giac's text fails. Write the oracle row as `[makesuite([1,2,3])]`: both sides then print a list.
- Ours returns `Sequence[...]` (it splices into the enclosing list), so the bracketed row compares the same elements.
- An empty sequence prints `seq[]` in giac: bracket it too (`[makesuite([])]` => `[]`).
