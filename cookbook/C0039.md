From 1.3/T9.c1 (CAS-585, 2026-11-23, sympy prototype .run/1.3/T9/risch.py, notes .run/1.3/T9/notes.md).
- Learn a helper's behaviour by calling the helper itself through caseval (`gcd(...)`, `factor(...)`,
  `lvar(ratnormal(...))`), never by tuning to the risch answers: 87/87 probes matched that way.
- giac `gcd` fixes the printed ln arguments: strips monomial factors; returns the first argument as is when it
  divides the second up to constant×monomial; flips sign only for a negative real leading coefficient; over sqrt
  extensions monic then denominators cleared. `factor` in sqrt mode splits quadratics only for a numeric discriminant.
- risch.cc:693 (ln case of `risch_poly_part`) passes `allowed_lnarg=0` to the last `in_risch`, dropping the
  one-log restriction of a nested call: giac returns antiderivatives that fail differentiation (batch rows 19, 30, 116).
  Verify every prim by differentiation before trusting giac's row as the reference.
- Tower order: kernels by tree size; size ties follow giac's ratnormal print order (not portable): tie rows differ
  in shape or split (3 of 150 random rows); record as a departure, not a bug.
- Tower rules: exp(2x)+exp(x) → Z^2,Z; exp(-x) with exp(x) → Z^-1; constants split off (exp(2x+1) = e·exp(2x));
  a^x → exp(x ln a); ln(exp(u)) → u.
- Random batch vs giac (150 seeded towers, caseval, differentiation check) is the decision-correctness evidence:
  0 rows where one side integrates and the other leaves.
