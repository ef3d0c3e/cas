# A mode that reroutes one native to another that calls it back

complex_mode sends Factor to ComplexFactor (cfactor), but cfactor factors `i p` through Factor: rerouting at Factor's
entry loops forever.

- Split the rerouted native: Factor's old body becomes a plain function (`polynomial::factor_as_set`); the native
  checks the mode and delegates; the target (complex_factor) calls the plain function, never the native.
- Same check for Solve → CSolve (complex_solve must not call Solve's native with the mode on).
- Degree/grad mode in the trig natives: a ball times π stays a product outside N; approximate the argument first
  (`numeric::approximation`), and keep the original call when the converted answer still holds the head
  (`special::periodic` returns `±f[...]`).
