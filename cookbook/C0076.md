# Registry traps for new cas-core builtins: names and LISTABLE with a scalar argument

- A builtin's internal name must be an ASCII capital then ASCII alphanumerics (crates/cas-core/src/tests.rs
  `builtins_have_fixed_ids`): underscores or lowercase surface spellings (DOM_INT) go only in en.txt
  (`DomInt: DOM_INT DOM_int`). Not caught by build or clippy: only by CI's test job.
- LISTABLE never broadcasts a scalar (eval.rs `thread`, CAS-DOC-4 O8): `f[list, n]` with LISTABLE gives
  EvalError::Shape before the native runs. A builtin taking (list, scalar) is not LISTABLE; its native threads its
  first argument itself (1.6/T8 Truncate, native/truncation.rs).
- Oracle rows with decimal answers (or lists mixing exact and decimal entries) fail `agrees` (Equal does not decide
  them): route them through a within-error check (C0006); probe giac to see which rows are decimal.

Source: 1.6/T8.c4.
