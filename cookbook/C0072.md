# C0072 — Natives reading data outside State: Eval::volatile, no stamp or memo; Context Debug fields
tags: eval,memo,cache,native,context,clippy,session · date: 2026-11-25 · phase/task: 1.6/T7 · origin: T7.c1 CAS-620

# A value outside State that natives read: never stamped, never memoised

Problem: a native that reads mutable data kept outside the Context's State (the session history, the random generator)
returns different answers under one state id. The evaluator stamps fixpoints with the state id and memoises per call,
so `ans()` that stayed (empty history, out of range) would be served stale after the history grows.

Move: count the read the way `Eval::draw` counts a draw. `Eval::volatile()` (eval.rs, CAS-620) bumps the call's
`draws` only, never the context's `Random::draws` (which Trace::verify reads); the memo/stamp gate
(`if self.caches && self.draws == draws`) then skips the expression and every enclosing one, so `ans()+1` nested works.

Also: a new Context field goes into its manual `Debug` impl, or stable clippy fails `missing_fields_in_debug`;
stable clippy also flags `format!` collected into a String (`format_collect`).
