# C0020 — Porting giac's C integer code: truncated %, signed invmod, standalone rustc check
tags: giac,port,prototype,integer,rustc · date: 2026-11-23 · phase/task: 1.3/T2 · origin: CAS-552 bernoulli_mod, CAS-548 chrem

Porting giac's C integer code bit for bit (bernoulli_mod, ichinrem, invmod; 1.3/T2.c1, 2026-11-23).
- giac's int helpers return raw C values, not normalised residues: `%` truncates toward 0, `invmod(int,int)`
  (gen.cc:10628) returns a signed cofactor, so answers can be negative (bernoulli_mod(10,13) = -8). Emulate C
  truncated `/`, `%` (Python: helpers, never `//`/`%`), i64 for `longlong`, i32 wraparound where giac's int overflows.
- Prototype in Python first (C0009), then, since tests are CI-only, compile the Rust port standalone with
  `rustc -O` on a scratch main in .run/<phase>/ and compare to the probes before wiring it in (10/10 at T2.c1).
- giac decides per step, not per call (chrem: integer pair -> lcm path, else coefficientwise mod m*n): probe the
  mixed cases (constant polynomial residues, modulus 1, single pair) before writing the dispatch.
