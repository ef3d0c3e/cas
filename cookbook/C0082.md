# giac ports and clippy: full binding names; Warning::Native needs &'static str

- clippy's `many_single_char_names` (stable, -D warnings) fires at five single-letter bindings in one scope, and the
  native's own `e` parameter counts. giac code uses a, b, m, n, r, u, w, x, z: give bindings full names from the start
  of a port (hit by both T3 coders).
- A local `refuse(ev, e, why: &str)` helper fails with E0521: `Warning::Native { message: why.into(), .. }` needs
  `why: &'static str` (giac's messages are constants anyway).
