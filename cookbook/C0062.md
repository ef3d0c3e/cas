# Iterative float optimisers with a certified stop: test in balls, one shared work budget

From frank_wolfe (1.5/T6, crates/cas-core/src/native/optimization/frank_wolfe.rs, CAS-609).

- Make the certificate the loop's stop test, not a post-check: each iteration evaluates the gradient in
  balls at the iterate's doubles taken as exact balls (wp = working precision + guard), the Frank–Wolfe gap
  max_a ⟨∇f(x), x − a⟩ in balls, and stops only when its upper bound < tol. Direction and step use the
  balls' mids in doubles (giac's FW_backtracking / FW_step_size port, or find_minimum::search with exact).
  For convex f the gap bounds f(x) − min f, so oracle rows compare by value against the closed form.
- One budget of `terms` evaluations shared by every inner loop (backtracking, line searches, rand's
  restarts): each gap costs |A|·n + n, each f value 1. Clamping maxiter alone leaves inner loops
  unbounded (C0019).
- FW's O(1/k) rate: tol 1e-3 takes ~250-850 iterations on giac's rows; 2^-14 ~4k-14k; 1e-6 is not
  reached within 100000 (giac fails there too), so tests use tol ≥ 2^-14. Check counts with a Python
  prototype first (C0009).
- rand with a random restart set: checked on ours only, by value (C0044).
