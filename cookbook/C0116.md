# C0116 — Sweep skip guards test the drawn input, not the strategy flag; giac spaces .. in strings
tags: proptest,oracle,sweep,giac,modgcd,strings,departure · date: 2026-11-26 · phase/task: 1.8/T9 · origin: CI 45831113300 random_modgcd, random_words

A sweep's skip guard keyed on a strategy flag (`univariate in any::<bool>()`) misses draws that land in the excluded
case anyway: random_modgcd skipped giac's one-variable content departure only when `univariate` was set, and a
two-variable draw whose terms were all in `y` (`modgcd(-4*y,-2*y)`, giac `y`) went red on CI (1.8 T9, CI 45831113300).
Guard on the drawn input itself (here: the text lacks `x` or lacks `y`), and probe the departure in each variable
with caseval before writing the guard. Same for string generators: a giac lexer quirk applies to any drawn content,
so exclude by content (`writable` now rejects `..`, which giac spaces even inside a literal: `asc("..")` is
`[32,46,46]`). Pin each shrunk input as a plain departure row and transcribe the CI seed (C0110).
