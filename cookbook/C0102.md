# Two coders in one working tree: build in a detached worktree

When two coders share the working tree (parallel coders of one task), one's half-written module can break the
other's build (seen 1.8/T5: `native.rs` declared `mod leftovers_three` before the file existed).
- Build and lint in a detached worktree: `git worktree add --detach .run/<phase>/T<n>/wt HEAD`, copy your own
  changed files in, run the gates there with the shared `CARGO_TARGET_DIR` (reuses the build cache).
- Before pushing, re-run every gate on the combined head (yours + the other coder's commits) in the main tree.
- Remove the worktree when done (`git worktree remove`). Commit only your explicit paths.
- A CI failure in the other coder's files is reported, not fixed.
