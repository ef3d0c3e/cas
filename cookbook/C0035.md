# giac convex: symbolic Bunch-Kaufman ldl, and giac's ldl command as its oracle

From CAS-583 (T7.c1, 2026-11-23). giac's `_convex` (optimization.cc:8093) signs the D blocks of `ldl(Hessian)`;
the conditions it prints depend on ldl's pivot choice, so a textbook Sylvester test does not reproduce them.
- Port the non-LAPACK branch of `ldl` (vecteur.cc:16557, alpha=(1+sqrt(17))/8); numeric matrices take LAPACK doubles
  in giac: decide those exactly and note the edge.
- Pivot comparisons skip symbolic entries (`type!=_SYMB`), and giac treats abs(symbol) as > 0 when choosing pivots.
- Cheap oracle for the port: run giac's own `ldl(M)` through caseval (C0018); it prints perm, L and D, so a prototype's
  factor can be checked matrix by matrix (10 matrices, symbolic included, matched) before the convex answers.
- A 2x2 D block is read back from row 0 (`H[0][i+1]` holds the sub-diagonal after ldl), not from H[i][i+1].
