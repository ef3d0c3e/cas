# Option symbols that are also builtin aliases arrive as the builtin's symbol

Context: giac options such as `convert(f, partfrac)` are bare names. When the option name is
also an alias in crates/cas-lang/names/en.txt (`Apart: partfrac`), the language lowers it to the
builtin's symbol (`Apart`), not to a symbol named `partfrac`.

Move: in the native, match both the bare option name and the builtin symbol it lowers to
(crates/cas-core/src/native/bits.rs `convert_to`, CAS-529). Without it the call stays unevaluated.

Check: before matching on `option.as_symbol().map(Symbol::name)`, grep en.txt for the option
name; every hit on an alias line needs the builtin symbol as a second pattern.

Also: the parser rejects giac's quoted names (`'L'`); an oracle row sends giac the quoted input
and evaluates ours on the unquoted one.
