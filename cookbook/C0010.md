# Numeric tests on complex balls: compare Re and Im, never Abs

`Abs` of a complex ball that holds 0 in a part is INDETERMINATE here: `ComplexBall::abs`
(crates/cas-num/src/ball/complex.rs:281) is `sqrt(re²+im²)`, a square of a ball around 0 dips below 0, and
`Ball::sqrt` (ball/real.rs:372-388) gives INDETERMINATE (Arb would give [0, ub]). So `Less[Abs[z - exact], tol]`
never evaluates to True when z is a root ball with a zero part (±i, x^4-2's roots).

- Compare `N[a - b, 30]` part by part: `Abs[Re[d]] < tol` and `Abs[Im[d]] < tol` (crates/cas-giac/tests/real_roots.rs
  `close`, as statistics.rs does).
- For enclosure checks, take the ball endpoints as rationals and decide exactly (polytools/tests.rs `holds_root`).
- Decode a ball's hex midpoint with `float.fromhex` before calling it off: 0x1.0000000000048c02p+0 is 1 + 1.6e-14,
  not 1 + 4e-12 (T4 misread).
