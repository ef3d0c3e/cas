# Printer departure rows without running ours: the prototype on our lowered shape

When a printer port (giac's markup/mathml) is checked by a Python prototype and our answers are seen only on CI (R74),
a departure row (giac's evaluation leaves another shape than ours: term order, -(1+x), rewrites) still needs OUR
expected text before the push.

- Lower our evaluated form by hand into the prototype's giac-shaped tree (the same shape markup/lower.rs builds:
  our order, Times[-1,..] as neg, inv for negative powers), run the prototype's printer on it, paste that text as the
  row's expected "ours"; keep giac's raw text beside it.
- Sanity check: the same lowered shapes must reproduce the departure texts already recorded for another printer
  (1.6/T5.c2: the 17 MathML departures' shapes gave T4's 17 LaTeX departure texts exactly).
- Script pattern: .run/<phase>/T<n>/c<k>/deps.py (scratch; rebuild per task).
- Trap: a scratch table rewritten by a mutation run (deliberate breakage to test the checker) is stale; re-run the
  checker before building a committed tsv from it.
