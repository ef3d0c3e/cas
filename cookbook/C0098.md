# Unit-test full forms: no decimal literals, capital user names print as `$A`

- cas-core unit rows written with `Expr::parse_full_form` cannot hold decimal literals (`1.1` fails to
  parse): use an exact value or build the Real in code (1.8 T3.c2, FillValue).
- cas-lang lowering tests: a user name starting with a capital lowers to `$A` in full form (it is
  escaped from builtin spellings), so expected text says `Set[$A, …]`, not `Set[A, …]`.
- CI's `cargo test` stops at the first failing crate: a red cas-core leaves cas-lang's tests unrun, so
  one push can hide the next failure. Check every changed crate's tests before pushing.
