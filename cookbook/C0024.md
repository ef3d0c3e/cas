# giac list ports: no conjugation in vector products, NULL written unquoted

Found at T3.c2 (2026-11-23, multiply and subsop, CAS-558/559).
- giac's `*` of two vectors (`multiply`, `_prod`, misc.cc:2379) is the plain sum of products over the shorter vector,
  no conjugation: `multiply([1,i],[1,i])` = 0. Our `Dot` conjugates, so a port uses `linear::dot` directly.
- giac's examples quote deletions (`subsop(l,'1=NULL')`); our parser cannot read the quote and `NULL` lowers to the user
  symbol `$NULL`. Write oracle rows unquoted (`subsop(l,1=NULL)`), which giac answers the same at top level; ours treats
  `$NULL`, `Null` and an empty `Sequence` as deletion. Exception: giac's unquoted nested `[1,1]=NULL` does nothing
  (departure row).
