# giac function answers: compare them applied, not printed

giac prints a function result (function_diff(sin), unapply, ...) as a lambda with a hidden
parameter: ``(` x`)->cos(` x`)``. `Giac::agrees` cannot read the backquoted name back, so a
row on the bare function never agrees.

Move: write the oracle row on the applied form instead: `function_diff(sin)(x)`,
`function_diff(ln)([x,y])`, `function_diff(ln)(2)`. The bare printed form goes to `departures()`
with libgiac's own text (C0015) and ours (`(x)->cos(x)`).

Related traps (stable clippy, 1.3 T6.c1): `(1..).find(..)` trips `maybe_infinite_iter` (bound the
search); five or more one-letter bindings trip `many_single_char_names` (module-level
`#![allow(clippy::many_single_char_names, reason = "...")]` for ported formulas). New files: format
with the stable rustfmt before `cargo fmt --all --check` (C0003).
