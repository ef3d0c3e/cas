# C0050 — giac symbolic linsolve: free parameters make comparisons skip, port the skip
tags: giac,port,linsolve,prototype,tpsolve · date: 2026-11-23 · phase/task: 1.4/T6 · origin: CAS-598 tpsolve zero supply

Porting giac code that solves a system symbolically (`_linsolve`) and then compares the solution (CAS-598 tpsolve, 1.4/T6, 2026-11-23).
- An underdetermined system leaves free parameters in giac's solution; `is_strictly_greater(a, c)` on a symbolic `c` is false, so the comparison silently skips those entries. A port that solves numerically must reproduce that skip, not fail.
- tpsolve: a zero supply or demand splits the MODI basis tree; giac answers `tpsolve([0,20],[15,5],[[1,2],[3,1]])` = 50,[[0,0],[15,5]]. Port: potentials per connected component (each extra component rooted at 0), and a reduced cost whose row and column lie in different components is never chosen (crates/cas-core/src/native/optimization/tpsolve.rs `potentials`).
- Found by a Python prototype + random-input batch against caseval (C0009); zero-valued sizes were absent from the first 120 random inputs: include zeros and empty-ish edges in every random batch.
- giac doubles like `epsilon(ctx)/(m n+1)` port as exact rationals (10^-12/(mn+1)); its final `epsilon2zero`+`exact` on integer-valued plans is rounding each cell to the nearest integer.
