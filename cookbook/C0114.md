# Before a sweep, run its generated inputs in ONE giac process

caseval (C0018) runs each line in its own child, so a giac heap overrun that aborts only later in the same process stays invisible. The oracle test binary shares one libgiac for all its cases: CI died with SIGABRT ("corrupted size vs. prev_size") on `splice` with a crossfade longer than a clip. Generate a batch of the sweep's inputs (a few thousand) and evaluate them in one process; the overrun showed within 150 lines (1.8 T8.c3). Exclude the class in the generator; existing fixed rows in the same class (sound.rs `splice(a,createwav([0.9]),3,1)`) are suspects too.
