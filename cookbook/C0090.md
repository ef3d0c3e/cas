# Designing a Kaiser-windowed sinc table for bandlimited resampling

When: building a polyphase/Smith-style resampler from a tabulated windowed sinc g(x) (zero crossings at integers, half-width H, L points per unit, linear interpolation between entries).

- Kaiser: β = 0.1102(A − 8.7); taps M ≈ (A − 7.95)/(14.36·Δf), Δf the full transition in cycles per sample; put the stopband edge at the lower Nyquist, cutoff mid-transition, kernel scaled by ρ = min(1, nsr/sr) when downsampling.
- Kaiser's β(A) leaves passband ripple a little above δ = 10^(−A/20) near the band edge; widening H moves the edge away from it. Measured (T8): H = 37/86/312 for 100/120/144 dB at 80/90/96 % bandwidth, where Kaiser's formula gave 29/74/232.
- A linearly interpolated table sags the passband by about (πf/L)²/3: size L from the passband ripple budget, not from the table error alone (L = 512/2048/8192, where π²/(24L²) ≤ δ gave 256/1024/4096). The table error is ≈ 1.00x·π²/(24L²): the window's curvature adds a hair (0.2 % at 100 dB).
- Measure the response of the interpolated table exactly (its transform, the first image included) by FFT at 10-20 points per sidelobe; at 4 points a 143.6 dB stopband read 144.9 dB.
- Oracle rows on f64 results that are then quantised: keep only cases at least ~0.03 of a code from a rounding tie, so prototype and Rust agree.
