# Workspace clippy is pedantic: load checks as assert!, names in backticks

- `if !ok { panic!(...) }` fails `clippy::manual_assert`; write `assert!(ok, "file:{line}: ...")`.
- Identifiers with `_` in doc comments (`aide_cas`, `en_docs.txt`) need backticks (`doc_markdown`).
- Check with stable clippy locally (C0003) before the push; CI's clippy job uses `-D warnings`.
