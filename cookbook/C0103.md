# giac clustering index= traps: hclust silhouette aborts, message without a period

- `cluster(data,index="silhouette")` (also `index=true`, `"all"`, lists with silhouette) hits an assertion
  (optimization.cc:11325 `jt!=bm.end()`) and aborts the libgiac process whenever `max_k ≥ N` and a merge
  happens; the default `max_k` is 16. `count=a..b` with `b<N`, or `count_sup` (clamped to N−1), is safe.
  The oracle runs libgiac in-process: never send abort rows; check them on ours only (departure row). Probe in
  caseval first (one child per line, C0018, C0021).
- `mcclain-rao` and `dunn` are accepted names but compute nothing; `output=index` then answers giac's
  "Unable to transpose" — with no period before " Error:". Oracle message extraction must not assume ". Error:".
- `kmeans` takes other names (cluster_crit::name2index, :11060-11076: calinski-harabasz… ; "log-det" maps to the
  det ratio), `index=true` = calinski-harabasz; `output=index` is `[[k,value]…]` with "not defined" for undef.
- output=part prints as `list[...]` (the LIST subtype) in caseval.
