# C0110 — proptest failure on CI: transcribe the printed cc seed into tests/<file>.proptest-regressions
tags: proptest,regression,ci,oracle,seed · date: 2026-11-26 · phase/task: 1.8/T7 · origin: CI 45818464735 random_modgcd

A proptest! sweep in `crates/cas-giac/tests/*.rs` that fails on CI leaves no file to commit: proptest's
`SourceParallel` persistence finds no lib.rs beside the test and saves on the runner only. The job log prints the seed:
grep it for `proptest: Saving` and the line after it, `cc <64 hex>`, plus `minimal failing input:` (multi-line).
Create `tests/<file>.proptest-regressions` with proptest's 6-line header (copy `tests/polynomials.proptest-regressions:1-6`)
and the line `cc <hex> # shrinks to <the minimal input on one line>`, as proptest's log asks. Also pin the shrunk input
as a plain row (agreement or departures), since a seed replays only while the generator is unchanged.
Logs: `gh api repos/ef3d0c3e/cas/actions/jobs/<id>/logs > .run/<phase>/…` then grep (C0004).
