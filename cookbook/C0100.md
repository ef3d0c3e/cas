# giac oracle rows: 12-digit decimals, process-global session state, subst form

From 1.8 T4.c1 (crates/cas-giac/tests/gap_leftovers.rs):
- giac's printed decimals (12 digits) read back as tight balls, so `Giac::agrees` fails on float answers
  that are right: compare `|N[a-b]| < 1e-9`, entry by entry for lists (`near` helper).
- giac's assumptions and `addtable` pairs are global to the libgiac process and survive `restart`
  (re-adding a pair answers 0): session rows use a variable no other row in the test binary uses and
  compare only the last value.
- Write giac rows as `subst(e, x=2)`: ours does not evaluate giac's `subst(e, x, 2)` form; giac takes both.
