# A native that applies the user's functions

Context: giac commands taking `x->body` arguments (simulated_annealing's cost and step). `x->body` lowers to
`Function[{x}, body]` (cas-lang lower.rs:1341).

- Check the shape at entry: head `Function`, its first argument a list of the expected number of parameters; else Ok(None).
- Apply with `ev.eval(&Expr::apply(f, &args))`: the evaluator's step 5 (eval.rs:859-869) substitutes; each call runs
  under the evaluator's limits and the interrupt.
- A value the native needs as a number: evaluate `N[f[x]]` (giac's `evalf_double`); an exact start (x0 = 2) gives
  `4 + Sin[40]/5` otherwise, which is no number. Then to_f64 + total_cmp (C0028).
- The user's `rand` and the native's own draws (`ev.draw`) share the session generator, so `SeedRandom[s]` repeats a run.
- First use: crates/cas-core/src/native/optimization/simulated_annealing.rs (1.5/T7, CAS-610).
