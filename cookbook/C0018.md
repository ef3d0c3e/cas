Tests are CI-only, so call the library directly from Python:

    from ctypes import CDLL, c_char_p
    g = CDLL("libgiac.so.0"); g.caseval.restype = c_char_p; g.caseval.argtypes = [c_char_p]
    print(g.caseval(b"rat_jordan([[2,1],[0,3]])").decode())
