# Decimals in cas-core full-form unit tests: write them as hex floats

Found at T4.c1 (2026-11-23, CAS-593).
- The full-form reader used by cas-core unit tests does not read `0.5`; write decimals as hex floats
  (`0x1p+0`, `0x1p-1`, `0x1p-40`), which read as exact binary decimals.
- giac's error text through `scripts/caseval.py` has its newline shown as ` | `; the library's own string
  (what `Giac::value` returns on CI) has `\n` there: compare departure texts with whitespace collapsed.
