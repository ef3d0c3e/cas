# CI-only tests of a big port: one test per row group that collects every failure

From 1.3/T9.c3 (CAS-585, 2026-11-23, crates/cas-core/src/native/integrate/risch/tests.rs).
- When tests run only on CI (card: no local cargo test, no local evaluator runs, R32/R33), a port of ~2000 lines
  reaches CI unrun. Write one test per row group (required rows, other probes, partial, unevaluated) that loops
  over its rows, collects `(input, ours, expected)` for every failure and panics once with the whole list: one CI
  round shows all mismatches instead of the first per test.
- Expected values come from the oracle's own answers (probe.out) and the prototype's trace (`risch.py --one`),
  generated into the test table by a scratch script, never retyped.
- Check antiderivatives twice: equal to giac's (Together of the difference; TrigToExp + TranscendentalSimplify
  for trig rows, E^u read as Exp[u], C0036) and D(answer) − f = 0, so a giac shape mismatch is told apart from a
  wrong answer.
- `tools/commit_task.sh` refuses a deleted path: `git rm` it, then commit_task with no path arguments.
