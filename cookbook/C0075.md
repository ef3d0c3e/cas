# giac's uppercase HP/TI command is not always an alias of the lowercase one

Probe both spellings through scripts/caseval.py before putting a giac uppercase name on a lowercase builtin's line.
1.6/T8: SVL is svl (same C function `_SVL`, rpn.cc:2330), but SVD differs from svd: SVD lists singular values
ascending with U, V columns reversed; svd lists them descending. giac's svl/SVL do not sort at all
(SVL([[1,4],[4,1]]) = [5.0,3.0]). QR/LU store into variable arguments, unlike qr/lu.
