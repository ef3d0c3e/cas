## Answer

Recommendation: Tauri 2 (webkit2gtk-4.1) + Monaco with monaco-languageclient for the editor, KaTeX (or MathML) for math, uPlot or Plotly for 2D, three.js or Plotly for 3D, tested with tauri-driver + WebKitWebDriver under xvfb-run on ubuntu-latest. Reasons are in Findings. Fallback: Tauri + CodeMirror 6 if the @codemirror/lsp-client maintenance state is acceptable.
Key risks: @codemirror/lsp-client repo archived 2026-04-15 (moved); the webview snapshot tolerance must be built by us; webkit2gtk-4.1 is a system dependency.

## Findings

Fetched 2026-11-27 unless noted. Dates are the sources' own dates.

- Tauri 2: official CI guide (fetched 2026-11-27) lists apt packages libwebkit2gtk-4.1-dev, libayatana-appindicator3-dev, webkit2gtk-driver, xvfb; runs `xvfb-run yarn test` on ubuntu-latest; installs `cargo install tauri-driver --locked`. Guide suggests fail-fast: false and running cargo test before WebDriver. Caveat (third-party PR, hyprnote #1806): on Ubuntu 24.04 WebKitWebDriver lands outside PATH, and starting tauri-driver before Xvfb is up fails; fix is symlink plus xvfb-run wrap. No latest Tauri version number confirmed in this run.
- Tauri 2 targets webkit2gtk 4.1 (since alpha.3 blog). Debian/Ubuntu: libwebkit2gtk-4.1-dev.
- CodeMirror 6 + @codemirror/lsp-client: MIT. Transport interface is send/subscribe/unsubscribe, so a Tauri-IPC transport is simple. README does not list completion/hover/diagnostics/semantic tokens/signature help; we would verify these ourselves. Repo "archived by the owner on Apr 15, 2026" and moved to code.haverbeke.berlin/codemirror/lsp-client (github.com/codemirror/lsp-client, fetched 2026-11-27). npm page fetch returned 403; version unknown. Earlier search suggested 6.2.x line (unverified date).
- Monaco + monaco-languageclient: v10 released 2025-09 (typefox blog, 2025-09-25), bidirectional LSP-to-Monaco bridge; 10.2.0 dated 2025-10-20; a 2026 pkgstats listing shows 10.7.0 (unverified date). WebSocket JSON-RPC from vscode-ws-jsonrpc (merged into the repo). Our stdio child process needs a bridge (Tauri command/IPC or local WebSocket); confirm custom reader/writer transport support in v10 before committing.
- egui/eframe: 0.33.0 (highlights: egui::Plugin, kitdiff, kerning; MSRV 1.92); 0.33.3 exists; eframe 0.34.0 and 0.36.1 are on docs.rs (so 0.33 is not latest). Sources mostly third-party mirrors (newreleases.io), not official notes. egui_kittest: default threshold 0.6 (max YIQ weighted per-pixel distance), per-OS kittest.toml with threshold and failed_pixel_count_threshold (default 0); Rerun's re_ui uses lenient thresholds on macOS and has TODO(#12450) about running lavapipe in CI, so lavapipe in CI is not yet a proven path. No official egui_kittest + lavapipe recipe found. Editor: no LSP widget; must build. No MathML/LaTeX path; RaTeX (pure-Rust KaTeX-compatible) is young. Plotting: egui_plot (2D, not verified current version); 3D needs custom wgpu.
- iced: 0.14.0 released 2025-12 (GitHub release; Phoronix coverage); reactive rendering, time travel, headless testing via iced_test (Simulator, PNG snapshot create-if-missing, SHA-256 hash comparison; no tolerance option seen for 0.14). 1.0 not confirmed as shipped. plotters-iced not verified. No LSP or math path.
- Slint: 1.14 announced 2025-10-21; later 1.17.0 seen. Triple license: GPL-3.0-only OR Royalty-free OR commercial, so GPL-3.0-only is directly usable. i-slint-backend-testing: described as preliminary API for a headless backend. Editor and math: must build.
- GTK4: gtk4-rs 0.10.x (2025 line, 0.10.3 latest seen); gtk4 0.11.4 on docs.rs (MSRV 1.83); relm4 0.11.0 docs.rs build failed, last good 0.10.0. No GtkSourceView LSP client found in scope. Not verified: GTK/gtk-rs LGPL licensing (GTK is LGPL-2.1+, compatible with GPL-3.0), webkit6 crate for embedded WebKitGTK 6.
- Qt via cxx-qt: cxx-qt 0.8.0 release notes (build-system release, "18 Dec", year unconfirmed); cxx-qt 0.9.0 on docs.rs (latest seen). Qt 6 offers LGPL-3.0 (compatible with GPL-3.0-only); commercial alternative. Qt Data Visualization and QtWebEngine could cover plots/math, but no source checked for 2026 status.
- Dioxus desktop: 0.7 line on wry 0.53.x (0.7.0 with Subsecond hot-patch, Dioxus Native WGPU renderer); final 0.7.8; 0.8.0-alpha.1 listed. Same webview model as Tauri, but less mature desktop tooling; no tauri-driver equivalent verified.
- Newer toolkits: Zed 1.0 shipped 2026-04-29 (macOS, Windows, Linux). GPUI (Zed's UI framework) is Apache-2.0; Zed editor is GPL-3.0 (per Zed overview). GPUI as a standalone embeddable library has no verified stable API. Xilem: xilem 0.4.0 (Apache-2.0), pre-alpha per homepage; Linebender lost two core members to Canva in Q1 2026 (Linebender TMIL Q1 2026). Not recommended for a 2026 plan.
- Math rendering: WebKit MathML Core is on par with other engines per Igalia 2026 WebKit Contributors Meeting slides; WebKitGTK 2.51.1 gates MathML Core behind CoreMathMLEnabled (default state unverified). KaTeX output is deterministic, so pre-render to HTML (Node or Rust side) to avoid runtime JS dependence. KaTeX and MathJax are both JS; pure-Rust options: RaTeX (young), latex2mathml crate (not verified this run).
- Headless CI on ubuntu-latest: lavapipe/llvmpipe works for Vulkan/wgpu tests but is slow; llama.cpp CI pins ubuntu-24.04 and installs Mesa from kisak-mesa PPA (source: github.com/ggml-org/llama.cpp PR 10809 pattern). No source confirmed the default Mesa on ubuntu-latest. Pin an image explicitly.
