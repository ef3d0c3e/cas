Done: NLPSolve reads the 14 nlp_* option builtins by symbol with giac's forms, sends linear programs to LPSolve (exact), and solves integer/binary nonlinear programs (enumeration, else B&B); CI green on 67bbf0c; CAS-604, CAS-605 done.
Summary: nlpsolve now understands every option giac documents: starting points and regions, iteration limits, precision, tolerance, the method names, maximize and nonnegativity, and the presolve and verbose switches. Linear problems are handed to the exact linear solver, as giac does. Problems with integer or binary variables are solved by trying every integer point when the box is small, and otherwise by branch and bound on certified relaxations; exact answers come back wherever the objective is exact at integer points. Most integer problems where giac itself fails are now tested against their known optima.

Decisions:
- LP routing builds an `LPSolve[...]` call and runs lp_solve (reuses T2/T3 options, decimals → rationals, warnings); point reordered to our sorted variables.
- Every nlp_method value (and [name, "param"=v…] by shape) runs our one certified method; unknown string or symbol value → call stays with a warning.
- nlp_iterationlimit=n caps outer iterations at min(n, 60); stopped unconverged → warning "nlp_iterationlimit reached before the search converged", call stays (giac: "Failed to optimize at given precision": departure).
- nlp_precision: bits doubled up to min(4096, number_bits) until radius ≤ r·max(|mid|,1), else warning, call stays.
- Integer ties: lexicographic order, first variable most significant, first strict optimum kept; no feasible point → call stays, "no integer point is feasible"; node cap → incumbent + warning.
- nlp_initialpoint several-points matrix form: the call stays (not in the done-when).
Deviations:
- Precision relative bound has an absolute floor (max(|mid|,1)): a zero optimum cannot meet a relative radius.
- Ported giac's single-variable linear inequality → variable bound (optimization.cc:6833-6855): giac's 5-variable product row stayed unevaluated without it.
- Certification skips the side check for one-point ranges (B&B creates them).
- Expert edited two files itself (interpolation test fix, clippy loop fix), each a few tool calls.

- Unbounded linear program: giac `+infinity`, ours LPSolve's `{∓Infinity, {}}`: departure.
