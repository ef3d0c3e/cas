## Decisions
- Variables: `f.symbols()` minus builtins (canonical order; x1 < x2 as giac's _lname).
- Limits: |A|·n ≤ terms else warn; maxiter, rand count clamped to terms/(|A|·n); exact=n clamped to terms; plus one shared evaluation budget = terms over all runs (gap |A|·n + n per iteration, f value 1, gradient n) so backtracking/search/rand stay bounded (C0019). rand out of budget with a certified answer: answer + "past the limits" warning.
- Stuck (maxiter, zero/absorbed step, gap ≤ 0 in doubles) → "frank_wolfe: unable to minimize at the given precision"; NotReal (f/∇f non-finite) → Ok(None) silent.
- Certified stop: gap ball at wp+32 bits at the iterate's exact doubles, vertices as their exact balls; valid for convex f even if x is a rounding outside the hull.
- Coordinates: rational or finite decimal only (decimal via to_f64, C0028); x0 default = exact rational mean → double.
