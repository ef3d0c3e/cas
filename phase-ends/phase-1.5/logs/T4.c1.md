## Deviation (for the expert)
- nlp_precision test is `rad ≤ r·max(|mid|, 1)`, not `r·|mid|`: a zero optimum (giac's own `(x-1)^2+(y-2)^2` row) has a value ball with |mid| ≈ rad, so a pure relative test never passes. Documented in the module doc.
- Bare `NLPInteger`/other bare words: call stays silently (giac: "Invalid argument").
- A linear program whose bound names a variable absent from objective and constraints: LPSolve leaves the call, so NLPSolve stays (edge, untested).
- `doc/algorithms` chapter not touched (not in brief).
