## Decisions
- comparator: `Less[a,b]` or `f(a,b)` evaluated; True/False only, anything else -> `Halt::Undecided` -> call stays, no warning (giac's default sort orders symbols: heappush([5,3],x) = [x,3,5] is a departure row).
- giac's heapify/heappop test `args.type==_SEQ__VECT` (a subtype constant against the type): never true, so giac never reads their comparator; ours accepts `f` for all three (doc says so).
- groupermu: giac's `est_dans` range always covers all of `s` (invariant len = q+k+1), so a HashSet gives the same order; cap checked before each push: `count * n > MAX_ELEMENTS` -> refuse "calculation size limit exceeded".
