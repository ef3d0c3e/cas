## Changed
- new `crates/cas-core/src/native/dsolve/variational.rs` (`//!` cites optimization.cc `_euler_lagrange`, `_jacobi_equation`/`parse_functional`, `_conjugate_equation`/`strip_constants`); dsolve.rs `mod variational; pub(super) use variational::{…}`.
- EulerLagrange: forms `[L]` (t = x if L has x, else t), `[L,t]`, `[L,y[t]]`, `[L,{x[t],y[t]}]`, `[L,t,y]`, `[L,t,{u,v}]`. `y[t]` → symbol `y` (bare `y` counts, as giac), `y'(t)` → `EulerLagrange$du<i>`, y'' symbol `EulerLagrange$d2u<i>`; a leftover `y[..]`/`Derivative[n][y]` → stays. First integral (one unknown, L free of t) `du L_du − L = K`, then per unknown `L_du = K` (L free of u) else `L_u − d/dt L_du = 0`. Sides `Simplify` (giac simp+radsimp; `Together` alone leaves `(u²−(1+u²))/√(1+u²)`, not idempotent). Constants `$K_0…` per call skipping call's names (`$`: cas-lang `escape_name` for capitalised user names; plain `K_0` would not print). One equation unwrapped.
- giac's `solve_quiet(...).empty()` test is inverted, so giac never solves for y''; ours doesn't either.
- JacobiEquation: `[L,t,y,Y,h,a]` / `[L,y[t],Y,h,a]`, a must be `is_numeric`; partials by `Together`; `P=0` → True/False of `d=0`; else `Sequence[Equation[P' h' + P h'' − d h, 0], DSolve[{eq, h[a]=0}, h[t]]]`, the equation alone if DSolve stays.
- ConjugateEquation: `Together` then `FactorRational` (giac `collect`), strip numeric factors / sign (Times filter, `Power[b,-1]` recursion). `Simplify` was tried: gives `sin(1-t)` for giac's `cos(1)sin(t)-cos(t)sin(1)`, so Together.
