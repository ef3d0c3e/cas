## Answer

One recursive function `gen2markup(g, flags, idc) -> MarkupBlock` covers LaTeX and both MathML forms: each branch fills `latex`, `markup` (presentation) and `content` (content MathML) side by side under the flag gates. The Rust port needs only the LATEX, MATHML_PRESENTATION and MATHML_CONTENT arms (drop SCHEME). Correctness is checkable against probe4 for LaTeX and presentation MathML only. probe4 has NO content MathML or default (both-forms) examples: all 63 `export_mathml` calls pass `display`, which selects `export_mathml_presentation` (markup.cc:3820). Content MathML is unverified by any probe.

Priority rule:
- A child is wrapped when `child.priority >= parent.priority`, the parent operator's priority. Sites: 1443 (add, left), 1446 (add, right: `>= MUL`), 1427 (cplx), 1852/1858 (pointminus), 2269 (power left, `left.appl || left.priority>=EXP`), 2179 (exp), 1045/1049 (get_leftright), 1012 (assoc2markup), 2039 (product).

Minus (`prepend_minus`, 972-999):
- No-op unless `ml.neg`. If `priority > MUL` it parenthesizes first.
- latex: prefix `-` (or `\ominus ` when circled, 979).
- content: `<apply><minus/>...</apply>` (985, 987; mrow=true wraps with id).
- presentation: `<mrow><mo>&minus;</mo>...</mrow>` (992, 994).
- Then neg=false, priority=MUL, type=NEG (996-998).
- Negation flag: `at_neg` (1777-1781) flips `neg` on the child block rather than wrapping it. So `-(x+1)` distributes to `-x-1` (probe 61, 123) and `x*(-y)` gives `-x y` (probe 62, 124). In `-1/2`, neg = (num.neg != den.neg) (2104) and the fraction is wrapped in an mrow with minus (probe 2, 64).
