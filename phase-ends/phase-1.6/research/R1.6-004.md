## Answer

The LaTeX command is `_latex` (tex.cc:1468-1486). It calls `gen2tex` (1405-1460), which dispatches by gen type. Expression output lives in `symbolic2tex` (1270-1401), with helpers `prod_vect2tex` (303-323), `matrix2tex` (267-288), `_VECT2tex` (290-301), `idnt2tex` (622-690), `greek2tex` (530-619), `double2tex` (466-482, only when a flag is on). About 520 core lines (plus ~60 for spreadsheets, optional) are needed. About 865 lines are graph/plot code to skip.

Caveat: many probe4 outputs do NOT match the tex.cc literals (see Discrepancies). The Rust port must be tested against probe4.out, not against the source alone. Several rules are produced by per-function `texprint` hooks defined in other files (markup.cc, usual.cc, unary.cc), which I did not port-map.

### Numbers
- Integers and rationals: `_INT_`/`_ZINT` print via e.print (1415). Fraction `_FRAC` → `\frac{n}{d}` (1441). Probe: `1/2` → `\frac{1}{2}` (probe4:1); `-1/2` → `-\frac{1}{2}` (probe4:2); `2/3*x` → `\frac{2}{3} x` (probe4:60); `(a+b)/(c+d)` → `\frac{a+b}{c+d}` (probe4:58).
- Brace drop for 1/x: probe4:15-16 `x^-1` and `1/x` both → `\frac1{x}`. The source branch for at_inv on an identifier (1304-1306) gives `x^{-1}`, not `\frac1{x}`. The `\frac1{x}` form likely comes from a texprint hook (1281-1282). NOT located. Port must match probe4.
- Products: `\frac{num}{den}` built in the at_prod branch: 1340-1358. Denominator factors are at_inv args (1345-1346). The num/den group is emitted as `\frac{N}{D}`, and when a numerator follows a fraction group, ` \cdot ` is appended (1349). Probe: `a/(b*c)` → `\frac{a}{b c}` (probe4:59).
- Negative numbers: in a sum, a numeric term with `!is_positive` is printed via e.print, so the sign is inside the number (1324-1325). Unary negation: at_neg/at_plus with non-symb arg → opstring + gen2tex (1291-1293). Probe: `-x` → `-x` (probe4:10); `-x-y` → `-x-y` (probe4:12).
- Floats: double2tex (466-482) is used only if `specialtexprint_double` is on (1417). It prints `%13.6f`, or `%13g` if |d|>=1e30 (476-479). The `%13` width pads with leading spaces, so the flag-on output is not trimmed. The flag default is off (global.cc:6420). Default path uses e.print. Probe: `3.14` → `3.14` (probe4:32); `1.5e-7` → `1.5\times10^{-7}` (probe4:33). The `\times10^{-7}` form is NOT in tex.cc; it comes from the print path (not located).
- Complex: `_CPLX` → e.print (1421-1422). Probe: `1+2*i` → `1+2 \mathrm{i}` (probe4:29). `\mathrm{i}` is `tex_mathi` at markup.cc:50, set at markup.cc:200 and used at markup.cc:841. Complex factors with both parts nonzero are wrapped in parentheses inside products (prod_vect2tex 309-310).
- e and i: `e` → `\mathrm{e}` (probe4:27), `tex_mathe` markup.cc:51, 201. `i` → `\mathrm{i}` (probe4:28), markup.cc:50, 841. Neither is in tex.cc.
- pi, infinity (trailing space): idnt2tex(gen) 684-687: `unsigned_inf` → `\infty ` (685); `cst_pi` → `\pi ` (687). Probe: `pi` → `\pi ` (probe4:26); `infinity` → `\infty ` (probe4:30); `-infinity` → `-\infty ` (probe4:31). undef → `\,\mathrm{undef}\,` (688-689).
