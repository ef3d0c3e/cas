## Decisions / design
- Where giac errs, ours keeps the call and warns (Warning::Native); a symbolic dimension keeps it silently.
- REDIM(v,n<=0) = [] (giac). The r,c forms need >=1.
- newMat: r=0 -> []; a negative or zero dimension keeps the call (departure; giac uses abs).
- simult and changebase go through eval of Inverse and check that the result is a matrix. changebase wraps P^-1 A P in Expand.
- q2a: half the Hessian via D. It errs if an entry contains a variable or if Expand[q - form] != 0.
- upper/lower of a string change ASCII letters only (to_ascii_*).
