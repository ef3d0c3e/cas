## Findings (expert: bank these)
- generalizable: giac's hht puts the top of the frequency range (d == r exactly) in bin fbins-2, never fbins-1; an
  exact interior integer (x=80 of 161) stays; x=99.0005 → 99. Not explained by the source (:5455) or any f64
  operation order tried (probes in p7.cas tail). Ours mirrors: `if d == r && fbins >= 2 { h = fbins-2 }`.
- generalizable: arg of conj(z_{k-1}) z_k on hilbert output: noise sign of a ~0 imaginary part flips π to 0 under
  max(0,·). Ours sets im=+0 when its ball contains 0 (giac's exact zeros give π). Python with noisy FFT got
  `[[1,-1,1,-1]]` wrong (row 0 instead of 98); noise-free matches giac.
- caseval prints every `;`-separated statement: `L:=…;[…]` gives `[L, […]]`.
- giac's `stft(x,1)` error is the window's "Window size should be at least 2" (:5869), raised only when a frame exists.
