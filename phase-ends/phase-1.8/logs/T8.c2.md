- fracmod: prime moduli only (composite: departure "Reconstructed denominator is not prime").
- bernoulli_mod: even n only, p prime >= 5, skip (p-1)|n ("Not invertible"); p=2 crashes libgiac.
- icomp: k <= n (caseval: icomp(2,3,zeros=true) errs, as icomp(3,4)).

- type: only the right DOM_. CI 45823905195: type(-9/2)==DOM_INT giac false, ours `DOM_RAT == DOM_INT` held (== of distinct symbols stays). Departure of ==, not of type; no regression file written since the strategy changed (seed b5d9d7eb… no longer replays the input).
