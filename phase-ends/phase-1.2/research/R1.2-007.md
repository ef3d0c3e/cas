- Sturm (csturm.cc, `gen csturm_seq(modpoly & r0,modpoly & r1,vecteur & listquo,vecteur & coeffP, vecteur & coeffR,GIAC_CONTEXT)`): the remainder step is `DivRem(coeffP.back()*a,b,0,quo,r);` and the next element is `b= -r/coeffR.back();`. Bookkeeping: `coeffP.push_back(pow(b0,ddeg+1));`, `coeffR.push_back(g*pow(h,ddeg));`, `g=b0;`, `h=pow(b0,ddeg)/pow(h,ddeg-1);`. This is a subresultant-style PRS: pseudo-remainder with a power-of-leading-coefficient multiplier, then division by a stored denominator (coeffR.back()).

- VAS (model paraphrase, unverified): uses a Mobius map (a,b,c,d) starting at (1,0,0,1) rather than an explicit continued fraction. Steps: v0=variations(P); ub=posubLMQ(P); if v0==1 return interval (0, ap*ub); rescale p(x)->p(lb*x) when lb>16; shift x->x+1 via taylor(f,1,0,&Pascal); reversal for x->1/x. Endpoints: makeinterval(a/c,b/d). If the constant term vanishes the root is returned as a bare number `b/d` (push_back, not an interval). vas() splits negative roots via change_scale(w,-1) and res2=-res1 reversed.
- posubLMQ (model paraphrase, unverified): normalize sign to leading positive; candidates from negative-sign indices using log2 mantissa/exponent (compute_lnabsmantexpo); tempmin over n, tempmax over m; return `_ceil(65*exp(tempmax)/64)` (65/64 margin, ceiling). This is a plausible reading that would give 4 for x^3-7x+7 only if the numbers work out; NOT checked.
