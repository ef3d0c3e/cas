- crates/cas-poly/src/groebner.rs: `groebner_basis` now wraps private `basis_with(polys, order, &Work)` so several bases share one `Work` budget; `mod zero_dim;` + `pub use zero_dim::{MAX_NORMAL_SET, Rur, normal_set, rational_univariate, syzygies}`.
- crates/cas-poly/src/lib.rs: re-exports the five new items.
- crates/cas-poly/src/groebner/zero_dim.rs (new): `normal_set` (walk with pruning, sort under order), `Rur`, `rational_univariate` (rules a/b/c of the brief), `syzygies` (E-tag Lex elimination, then DegRevLex basis). Private: `Quotient` (basis + normal set, cap MAX_NORMAL_SET=256 -> TooLarge), `minimal` (incremental Gaussian elimination over normal forms of powers, rows carry the polynomial in l), `express`, ℚ[t] helpers (trim, derivative, mul, div_rem, gcd, squarefree).
- crates/cas-poly/src/groebner/zero_dim/tests.rs (new): normal sets; the 8 giac RURs of the brief; None cases; property test for x²−1,y²−1; TooLarge for x^300−1,y−1; syzygies of the 4 brief inputs (property: A-homogeneous, A-linear elements are syzygies; expected elements up to constant via `primitive`).
- doc/algorithms/groebner.md: sections Normal sets and the RUR, Syzygies, Ideal membership, Variable order for revlex; Tests paragraph. README.md chapter entry; references.md: [KR00], [Rou99], [Sei74], CLO15 §2.6/§5.3 noted.

## Decisions
- Shared `Work` via `basis_with` refactor (no behaviour change for `groebner_basis`).
- Seidenberg cited as [Sei74] (original paper) instead of a CLO section; section numbers of CLO15 §2.6/§5.3 and KR00 Ch. 3 written from memory, not checked against the books.
- `normal_set` (pub) is uncapped; only the RUR path caps at 256. Rur polys: coeffs from degree 0, no trailing zeros, 0 = empty vec.
- Fallback `Ok(None)` after n·D'² forms is unreachable (documented).
