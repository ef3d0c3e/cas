# T5.c3 — CAS-536: complex_solving comparisons decide

## Cause
- `near` took `Abs[a − b]`; complex ball `abs` = `sqrt(re²+im²)` (cas-num/src/ball/complex.rs:281); when a ≈ b the norm ball holds 0 → `Ball::sqrt` → `INDETERMINATE` (cas-num/src/ball/real.rs:373-387) → `Less` undecided → false.
- Hit closed_forms (all 4 complex rows) and departures printed-vs-recorded / ours-vs-decided (x^4+1, sin(x)=2). `values` passed only because giac's 12 digits keep the gap off 0.
- `cZeros(x^3-1,x)` via `agrees`: `Equal` of `(-1+i√3)/2` vs `-1/2+i√3/2` undecided (exact complex, `approximated` skips complex).
- `surd(-16,4)`: same `Abs` failure (gap ≈ 0 complex).

## Change (crates/cas-giac/tests/complex_solving.rs only)
- `near`: `g = N[a − b]`; for `Re`, `Im`: `Less[Abs[part[g]], N[(1+Abs[b])/10^9]]` must be `True`. `Re/Im` of ComplexBall → real Balls (native/parts.rs:97-108); real `Ball::abs` = `[|m| ± r]` (real.rs:431); `Less` of disjoint balls → `Apart(order)` (native/logic.rs:90, 316-330), decided both ways. Tolerance unchanged (1e-9·(1+|b|), C0006).
- `same_set` unchanged: injective matching + equal counts = bijection; now decides via `near`.
- new `expands_same`: lists, in order, `Expand[u − v] == 0`; cZeros(x^3-1,x) moved from `agrees` list to it.
- surd(-16,4) stays numeric (`near`): N of `(-16)^(1/4)` is principal √2+i√2.
