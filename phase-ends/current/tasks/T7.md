Decisions:
- binding: a sound clip is `SoundClip[rate, depth, {codes ch0}, {codes ch1}, …]` (surface `soundclip`, no native); codes signed, |k| ≤ 2^(b-1)-1, sample k/2^(b-1); well-formed check `sound::clip(e) -> Option<Clip>` (pub(in crate::native)) is what T8's natives take and give.
- binding: the clip prints as that call everywhere (session, string(), hook, LaTeX); lang_session and lang_print hold because it is an ordinary named call.
- Plus, Times, Part/At, Length and N treat it as any call: A+B stays, A-A = 0, -A and 2*A stay, size(A) = 2 + channels, A[0] stays, N(A) gives decimals (no longer a clip): departure rows.
- == : `equal`'s `known` includes a well-formed clip, so different clips (or clip vs number/string) are False, as giac's operator==.
- Caching: the natives are pure; nothing volatile.
- Encoding in f64 exactly as giac's double code (ratio 10^(-norm/20)/peak, clamp, floor(range·v+1/2)); lengths, slices, soundsec counts and duration exact.
- duration=d gives 1+floor(d·sr) exactly; giac's 47-bit doubles give one fewer for 0.001 and 1/1000 at 8000 Hz: departure rows (C0088).
- about(clip) answers the clip with giac's six property lines as a note; about(x) answers hold([facts mentioning x]) (Hold so re-evaluation cannot decide them, C0026), x itself with none; about(list) maps.
- createwav accepts size=/length= (our Length symbol): giac refuses size=; departure.
