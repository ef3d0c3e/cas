Decisions:
- binding: the analysis API contract lives in CAS-DOC-60 (product doc): one public module `cas_lang::analysis` (lines, cursor, symbols, docs); every query accepts any usize offset (past end → end, inside a char → floor) and returns ranges within the text on char boundaries.
- binding: `SyntaxError` gains `pub fix: Option<Fix>`, filled in `Parse::finish` (parser.rs:197) from new parser/fix.rs; `Fix` moves from lower.rs:144 to parser.rs, `cas_lang::Fix` unchanged; session.rs:276 copies it.
- Lines: breaks `\n`, `\r\n`, lone `\r` (matches lexer.rs:297-301); Utf8 and Utf16 only; line past the last → text end; column past content → content end; inside a char → floor (LSP silent, R2.2-006); `LineIndex` owned, no lifetime.
- Boundary rule (`cursor::token_at`, also `Symbols::at`): strictly inside → that token; at a boundary the left token wins if it is a word token (ident, keyword, number, superscript), a line comment, or an unclosed string/comment; else the right one.
- Cursor kinds: Comment, String, Number, Name{range}, Type{range} (after `::`), Other; empty spots give an empty Name/Type range; `call` = innermost unclosed ArgList, argument = commas before the offset.
- Symbols: occurrences = Name nodes; reserved names → one symbol per target; user kinds Function (has a rule definition) / Variable / Parameter / Local; scopes Document, Rule (whole Definition node), Lambda, Block (also an `if` with statements as a definition body); locals mirror lower.rs:1447-1452; globals one per key, order-free. Stable under an edit in another top-level statement (partition unchanged): ranges (shifted), definition flags, resolution. Not stable: ids, order, a global's kind and def/use lists.
- Fixes per kind: CAS-DOC-60 §5's table (Bar pairs per line, `&`/`&&` → and, `#` → //, LoneColon → `:=` or `;`, LeadingPoint, MisplacedUnderscore, UnterminatedString at the opening line's end, UnterminatedComment one `*/` per level, InvalidEscape escapes the backslash, Expected(k) inserts k, ExpectedSeparator → line break, Unexpected closer/end deleted, Tuple → list, NumberInProduct → `*`; the rest none).
- Docs: names/en_docs.txt (generated by scripts/doc_table.py from aide_cas pinned by sha256 c32a40d1…f2a8) and names/en_docs_overlay.txt (hand-edited); records keyed by target internal name with giac/sig/doc/see/ex/note lines; examples that fail parse or lowering hidden at load, count pinned by a test from CI; every [builtins] target gets a record; departure notes in the overlay from a scripted candidate list.
- Fuzz `lang_analysis` (T3 creates): at most 1024 sampled offsets per input; properties per task in §7; the stability property is a proptest in T6, not fuzz.
- No new dependency.
