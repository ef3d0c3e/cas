Decisions:
- binding: positions and lengths count Unicode scalar values (strings handled as Vec<char>); giac's byte answers are departure rows.
- `[lo..hi]` alone in a list is giac's real interval for contains (inclusive, real b only); otherwise first equal element.
- trim's default zero test: exact 0 or a decimal with |x| ≤ 1e-12 (giac is_zero with epsilon, gen.cc:9311); threshold t: |x| < t, t a positive real else stays; string whitespace 32 and 9..13; strip's default set " " only.
- left/right with one argument: Equation/Equal and Range only; giac's other symbolic forms (left(x+y) = x, left(a<b) = b) and the integer bit rotations stay.
- s[k] on strings follows the language's list indexing: out of range (also a slice past the end, "abc"[0..5]) is an error where giac cuts short; recorded as a departure.
- split's expression form: FactorList, then free-of x → y part, free-of y → x part, else [0].
