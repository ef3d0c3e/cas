Done: `cas_lang::analysis::symbols` indexes every name's definitions, uses, kind and scope on finished and half-typed text, with `at(offset)`; agrees with lowering (differential) and is stable under edits elsewhere (proptest); CI 46153101198 and Fuzz 46153101206 green on c1e3448f; CAS-668 and CAS-670 done.
Summary: The editor can now ask, for any piece of text, what each name means: a builtin, a type, a function, a variable, a parameter or a block local, where it is defined and where it is used, and which name sits under the cursor. It works on text that is still being typed. Tests check that it agrees with how the engine itself reads the same program, and that editing one statement never changes what the other statements' names mean. Building that agreement test found a real bug in the engine: in a curried definition such as `f(a)(b) := …` the engine forgot that `a` is a parameter; that is fixed.
