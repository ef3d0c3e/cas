Summary: When a user is in the middle of typing, the parser now has tests that fix exactly what tree and errors it gives for unfinished calls, lists, assignments and blocks. An unclosed call or list no longer swallows the complete statements typed on the lines below it. Most lexer and parser errors now carry an automatic fix that an editor can apply as one edit, for example `|x|` to `abs(x)`, `&&` to `and`, a missing `)` or `end` inserted, and `f'(x)` to `diff(f(x), x)`. The session passes these fixes on with its messages, and the fuzzer checks that every fix stays inside the text.
