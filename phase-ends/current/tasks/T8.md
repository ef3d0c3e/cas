Done: kovacicsols (KovacicSols) finds Liouvillian solutions of a*y''+b*y'+c*y=0 by Kovacic's cases 1-3, ported from giac desolve.cc; CI green on 263e564 (all 5 jobs); CAS-584 done.
Summary: The new kovacicsols command solves second-order linear equations with rational coefficients in closed form when such a solution exists, as giac's does. It was first written as a Python prototype that reproduced all seven of giac's example answers, then ported to Rust. Where giac's own code is wrong (case 3 with a first-derivative term, fractions in the list form), ours gives the correct answer and the difference is recorded as a departure. DSolve is unchanged.
