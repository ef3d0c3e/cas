Done: `risch(f,x)` is giac 2.0.0.21's transcendental Risch algorithm over exp/ln towers, ported via a checked sympy prototype; every antiderivative guarded by D; oracle rows, departures (Int among them), chapter; CI green.
Summary: The CAS now has giac's `risch` command, which decides whether a function built from exponentials and logarithms has an elementary antiderivative and finds it, writing the non-elementary exponential part with Ei. It was ported line by line from giac's source after a Python prototype matched all 87 giac probes and a random batch of 150 integrands. Every answer is checked by differentiation before it is returned, so a wrong antiderivative turns into an unevaluated call instead. The ordinary integrate command is unchanged and does not use it.

- What risch cannot integrate stays `risch(rem,x)`: giac's inert `integrate(…)` would be evaluated by our Integrate on read-back, so those rows are departures.
- giac's flaw at risch.cc:693 is kept (fixing it breaks ln(ln(x))/x); the D-check guard returns the call unevaluated instead of a wrong answer. risch.cc:837 double count fixed.

- Int: no alias, no builtin; departure rows `Int(sin(x),x)`, `Int(sin(t),t)` (ours stays the user call `$Int`).
