## Deviations from brief (expert: please judge)
- Exchange is NOT giac's per-interval (zero by bisection, golden between zeros). Prototype showed it fails: abs(x) deg 2 from Chebyshev nodes gives E=0 interpolation, then converges to a non-alternating set, err 0.2134 (not 1/8); min(...) deg 30 diverges (emax → 2e4). Replaced by a full exchange: grid of 16 steps between consecutive points of {-1}∪ref∪{1}, one point per same-sign run (largest |e|, golden-refined), merge, pad with an end when < N, window of N holding the global max with best min|e|. giac's version kept in .run/1.4/t7/remez_giac_exchange.py.
- One extra iteration after the stop rule fires (polish): without it x^3 deg 2 gave 0.75000000439 (fails the 1e-9 coefficient test).
- giac's `E > emin` break dropped (E signed in giac; our stop rule only).
- Exact fits (f = p/q): exchange finds < N runs; converged when max|e| on grid ≤ 64ε·max|f|. q normalised by its first term ≥ 2^-40·size(q) (1/x on [1,2] has q const ≈ 1e-16 in f64).
- Limits: n+m ≤ 100; N²·limit·reps ≤ limits().terms else warning + stays; cover cap min(terms/N², 2^16).
