## Decisions (reasoning)
- Fix on the error (`SyntaxError.fix`) over a `Parse::fix(&SyntaxError)` method: same shape as `Diagnostic.fix`; a method would re-materialise the text (`syntax().to_string()`) per call; only two construction sites change. `Fix` moves to parser.rs so parser does not depend on lower.
- One public module `analysis` (plan default kept); fixes live in parser/fix.rs since they belong to `parse`.
- Offsets in: any usize, clamp past end, floor inside a char — one contract for lines, cursor, symbols; makes every-offset fuzzing panic-free by definition.
- Line past the last: text end (spec silent). Inside a character: floor (spec silent, R2.2-006). No UTF-32 (proportionality).
- Boundary rule left-biased for word tokens: serves completion and signature help while typing, and `|sin` still hovers `sin` (left is whitespace). One rule for cursor and `Symbols::at`.
- Symbols: occurrences = Name nodes (ErrorNode idents excluded); globals one per key across the whole text regardless of order; Function iff a rule definition exists; binding forms recorded even where lowering refuses them; up-rule params do not remove block locals (mirrors lowering's `parameters`). Stability stated as a precondition (statement partition unchanged) plus what is and is not stable; ids explicitly unstable.
- Fixes: given only where plain. Rejected: Apostrophe → diff rewrite (needs the variable), ChainedEquation → `and` (duplicates an operand), ExpectedSeparator → `;` (would hide output; line break chosen), Bar on lines whose pairing is ambiguous.
- Docs: keyed by target internal name; examples kept verbatim in the generated file, hidden at load when they fail parse or lowering (no local Rust runs, R74); hidden count pinned by a test learned from CI (C0110 pattern). No CI freshness check: aide_cas ships in `xcas`, not installed on CI; sha256 pin instead. Departure notes hand-sorted from a scripted candidate list.
