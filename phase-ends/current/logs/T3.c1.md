## Decisions
- equality (find/index/count_eq): structural, else `Equal` == True when both numbers (giac finds 1 at 1.0: find(1,[1.0,2,1]) = [0,2]).
- count_inf/sup: counts only where `Less` evals to True (giac is_strictly_greater: count_inf(x,[1,2]) = 0); nested lists counted at every depth; non-list l counts itself (count_eq(1,1) = 1).
- row/col on non-matrix -> refuse "bad argument type"; other option symbols ignored (giac: count_eq(...,matrix) = 2).
- find/index exchange args when only the first is a list (giac's "Exchanging arguments"); index(1,[3,1]) = 1.
- string forms leave the call silently (phase 1.6); find's 3rd arg (start) and enumerate of 3+ args leave the call (departure rows).
- makesuite returns Sequence[..]; language cannot read a bare sequence -> oracle rows bracketed `[makesuite(..)]`.
- newList: non-integer or wrong arity -> refuse "bad argument value" (giac's text varies: size limit for 3/2 and (2,3)); |n| > MAX_ELEMENTS -> "calculation size limit exceeded". makevector > MAX_ELEMENTS args same.
- warnings lowercase as integers.rs.

## giac surprises
