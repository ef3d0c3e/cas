## Design (lines.rs)
- Stores `len`, `starts: Vec<usize>`, `breaks: Vec<u8>` (per line, last 0), `wide: Vec<Wide{start, len:u8}>` (non-ASCII chars). Offsets usize (no overflow); only `Position` fields saturate to u32 (`saturate`).
- UTF-16 width derived from UTF-8 len (4 → 2, else 1). Floor to boundary via `wide` binary search (MSRV 1.85: no std `floor_char_boundary`).
- `#[allow(clippy::len_without_is_empty)]` on `len` to keep the §1 signature set exact. Derives `Clone, Debug` on LineIndex (missing_debug_implementations lint).
