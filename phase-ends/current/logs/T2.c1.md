# T2.c1 — CAS-526: EZ-GCD method in cas-poly

## Changed
- `crates/cas-poly/src/gcd.rs`: `GcdMethod::EzGcd` (doc: MY73, Wang80, GCL92 §7.6); `mod ezgcd`; arms:
  - ℤ dense: `Modular | EzGcd` → `modular::dense`.
  - ℤ sparse: `EzGcd if several_variables(a, b)` → `ezgcd::integers`; else merged with `Modular` (Brown's). Merged because clippy `match_same_arms`.
  - ℤ[i] dense/sparse, prime fields dense/sparse → `Ok(None)`. ℚ, ℚ(i) via `over_numerators` unchanged (delegates).
- `crates/cas-poly/src/gcd/ezgcd.rs` (new): `pub(super) fn integers(ring, a, b, cancel) -> Result<Option<Cofactors<Sparse<Integer>>>, Cancelled>`.
  - Contents in main var via zippel's `Contents::of` (reused, made `pub(super)` with `exact`, `main_variable`).
  - `Points` (Random::new(SEED=0x455A_4743_4443), range from 1, +1 per round, TRIES=20 draws/range); point keeps lc_x(a), lc_x(b) ≠ 0.
  - 2 points/round, lower-degree image gcd kept; deg 0 → 1; deg = deg_x a (b) → division shortcut, else unlucky → next round.
  - f ∈ {a, b, a+k b, k=1..3} with deg f(α) = deg_x f and gcd_ℤ(g, h) of degree 0; u = γ(α) g / lc g mod p (symmetric), v = lc g · h; `lift_variables(γ f, x, point∩vars(γf), [u, v], [γ, lc_x f], lifting_prime(γ f))`; G = `primitive_part_in(lifted[0], x)`; exact division of a, b.
  - ATTEMPTS = 16 rounds, then `None`.
- `factor/lifting.rs`: `lifting_prime` moved here from `wang.rs` (now `pub(crate)`), `symmetric` `pub(crate)`. `factor.rs`: `pub(crate) mod lifting`. `wang.rs` imports `lifting_prime` from `super::lifting`.
- `gcd/zippel.rs`: `Contents` (+ fields), `Contents::of`, `exact`, `main_variable` → `pub(super)`.
- `gcd/tests.rs`: proptest `ezgcds_in_several_variables` (with_cases 100, n = 2..=3, `triples`-like terms) asserting `check_gcd(.., EzGcd) == Some(ring.gcd(..))`; unit `ezgcd_examples` (x+y, xy+1, xy−y, 2); `gcd_workload` accepts `ezgcd`.
- Docs: `doc/algorithms/gcd.md` new section "## EZ-GCD [MY73, Wang80, GCL92]" before Resultants (base algorithm, γ trick, prime, unlucky points, giac heugcd/modgcd/psrgcd/ezgcd mapping); "What is computed" paragraph on `GcdMethod::EzGcd`; Tests bullet. `README.md` gcd chapter line. `references.md`: [MY73], [Wang80] entries added (bibliographic details from recall: Moses & Yun, ACM '73 pp. 159–166; Wang, SIGSAM Bull. 14(2) 1980 pp. 50–60; worth a check).

## Notes for the expert
- Variant: `GcdMethod::EzGcd`; fn: `crate::gcd::ezgcd::integers` (private module); shared: `crate::factor::lifting::{lift_variables, lifting_prime, symmetric}`.
- `gcd` default does not choose EzGcd (docs say so).
- Known limit: if every f tried has a cofactor sharing a factor with the image gcd at every point, it gives up (None) after 16 rounds; proptest asserts Some, so a CI failure there would be this case.
