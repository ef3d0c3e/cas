## Decisions
- apply(f,l) builds `f(x)` list (as Map) for the loop; `matrix` option = Symbol::MATRIX (C0008); empty list -> []; non-matrix -> refuse BAD_TYPE (giac: ragged -> Bad Argument Type, vector -> f(1,'matrix') junk: departure). apply(f,x), several lists, other options: stay.
- foldl/foldr return the nested call unevaluated (giac symb_of + eval). 1 arg -> BAD_TYPE, 0/2 args -> BAD_VALUE.
- multiply: left fold of pairwise giac `*`; one list arg = its elements (giac's _prod sees the vector); vec·vec truncated to shorter then `linear::dot` (no conjugate: multiply([1,i],[1,i]) = 0; `Dot` builtin conjugates, not used); other shaped pairs `linear::dot`, EvalError::Shape -> refuse "invalid dimension"; else Times evaluated. vector longer than matrix rows stays (giac truncates: departure).
- insert: Integer position only (2.0 stays: departure); strings stay.
- subsop: port of prog.cc subsop; `Option` slots, None = deleted, filtered at end; deletion = `$NULL` (language lowers NULL to user symbol `$NULL`), Symbol::NULL, empty Sequence. `subsop(l,k,v)` = one rule. Nested position into a non-list element leaves it; non-list first arg stays (giac edits a call's operands: subsop(f(a,b),1=c) = f(c)).
- language cannot read giac quotes `'1=NULL'`: oracle rows use unquoted `1=NULL` (giac same answer at top level). Unquoted nested `[1,1]=NULL` giac leaves the list (empty seq flattens the rule); ours deletes, as giac's quoted form: departure rows.
