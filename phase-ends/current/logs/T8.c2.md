## Design change (deviation from brief numbers; brief allows H/L adjustment)
- Measured on the transform of the piecewise-linear table, C(f)/L*sinc^2(f/L) by FFT (>=20 points per sidelobe), first image included.
- First set (H 29/74/232, L 256/1024/4096): passband max|G-1| 1.90/1.88/1.65 delta (MISS); stopband q2 100.3 dB OK, q3 119.0 dB MISS, q4 1.05 delta (143.6 dB) MISS at fine resolution (coarse FFT said 143.9).
- Cause: linear interpolation droop (pi f/L)^2/3 ~ delta at the passband edge (q2 9.9e-6 vs delta 1e-5); kernel ripple itself 1.02/1.17/1.03 delta at those H.
- Final: q2 H 37 L 512, q3 H 86 L 2048, q4 H 312 L 8192 (`// was` comments in DESIGNS).
  - q2: passband 8.54e-6 (0.85 delta), stopband 102.0 dB, table err 1.572e-6.

  - q4: passband 5.44e-8 (0.86 delta), stopband 146.6 dB, table err 6.128e-9.
- Table error is 1.002/1.0005/1.0000 x pi^2/(24L^2) at any L: g'' at 0 is pi^2/3 plus the window's curvature; no H/L fixes the ratio; recorded, not chased.

## Decisions
- q0/q1 in i128 integers: num = x_i*nsr + f*(x_{i+1}-x_i), code = floor((2*range*num + nsr*one)/(2*nsr*one)); no clamp needed (|v| < 1).
- Positions never pass the last frame for q0/q1 (s <= len-1-sr/nsr); the clamp is kept anyway.
- Empty result (floor(len*r/sr) = 0): stays, warning "The resampled clip would have no samples" (giac's Debian: libsamplerate message).
- More than 3 args: stays silently (giac ignores extras; C0042).
- Limits: rate > terms, n*channels > terms, taps*n*channels > 1024*terms -> "Too many samples"; interrupt polled every 1024 outputs.
- Departure q2-q4 rows chosen with tie distance >= 0.03 codes (numpy vs Rust f64); stereo q2 at 22050 rejected (tie 0.004).

## Findings
- generalizable: a linearly interpolated windowed-sinc table droops the passband by (pi f/L)^2/3 (its transform is C(f)/L * sinc^2(f/L)); with L = 256 that is ~1e-5 at f = 0.44, the whole 100 dB ripple budget. Size L from the ripple: L >= pi f_p / sqrt(3 delta * share).
- generalizable: measuring Kaiser stopbands by FFT needs >= ~10-20 points per sidelobe (spacing 1/(2H)); at 4 points q4's 143.6 dB read as 144.9 dB.
- generalizable: Kaiser's beta(A) gives passband ripple slightly above 10^(-A/20) near the band edge (1.02-1.17 delta); widen H so f_p sits further from the transition.
- generalizable: the linear-interpolation bound pi^2/(24L^2) uses sinc''(0) = -pi^2/3; the window adds curvature, so a windowed table exceeds it by ~beta/(H^2 * pi^2/3) (0.2 % at q2).
