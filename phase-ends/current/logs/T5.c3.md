## Design
- Data: all-rational → exact; else exact ball midpoints (C0064) at p = wp + 32. m = Σ/N, v = Σ(x−m)²/(N−1).
- Closed forms: NormalPDF[m, Sqrt[v]] (ev.eval Sqrt on exact v), PoissonPDF[m], ExponentialPDF[1/m], GeometricPDF[1/m]; balls on decimals (no Together, C0083).
- Iterative: `Run::newton` (balls at p, f64 inverse Jacobian of mids, step −Y·F in balls, exact-midpoint iterates; stop when every |step|·2^(wp+4) ≤ |x|; ≤ 100 steps) then `Run::certify` = Krawczyk K = x − Y F(x) + (I − Y J(X))(X − x) on box radius |x|·2^(8−wp), widened ×2⁸ up to 8 times; K ⊆ X → answer K ∩ X.
- Budget: one `Limits::terms` counter; a score over the data costs N (cauchy, weibull profile, final λ), giac's-sums scores cost 1 (gamma, beta, weibull moment start).
- Weibull k_init: Newton on giac's unsquared moment equation from max(1, 1/v); on failure giac's start itself. Scratch check (Python, 20 simulated Weibull(1/2,1) samples of 1000): plain Newton from 1 leaves k > 0 every time → fallback k0 = 1; the profile Newton converges in 6 steps; |k − 1/2| ≤ 0.033, |λ − 1| ≤ 0.14.
- Cauchy γ answered as |γ| (score equations even in γ).
- Order of checks follows _fitdistr: arity (Bad Argument Type / Expected a sequence of two arguments), list, ≥ 2, real, then law name (Unrecognized after the data checks), then the law's checks.
- Deviation (my call): exponential data with a 0 rejected ("Expected a positive number") like gamma/weibull, since giac uses the same `is_positive(-x)` test (true at 0) in all three; proto.py used x < 0 for exponential. No row tests it.
- No root / budget spent: the call stays silently, except beta ("Unable to compute parameters for Beta distribution").
