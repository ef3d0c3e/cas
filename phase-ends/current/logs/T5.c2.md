## Design (as ported)
- Options in giac's order (:7305-7363); first arg not a list → LIST text before options (giac :7300). Option symbols matched as builtin or name (C0008): select→Select, gauss→GaussSquares, normal→Together, normald→NormalPDF, interp→InterpolatingPolynomial, spline→Spline, eval→Evaluate, exact→Exact, piecewise→Piecewise; range/output/Output/list by name.
- Data: rationals exact; numeric non-rationals by approximation midpoint (Ball::exact(mid), C0064). Exact form uses the given data Exprs.
- sd exact variance on exact data then Ball sqrt. ROT: giac's lower quartiles, 1.06, 1.34, n^(−1/5) in balls; ROT at 0 → plug-in (as giac, bw<=0).
- DPI exact path over distinct values with multiplicities (Σ_{u<v} m_u m_v f + Σ C(m,2) f(0)): equal to giac's i<j sum, far fewer exps on repeated data. DPI bins path via integer autocorrelation of counts (full ordered sum, as giac).
- Grid: [min,max] when DPI (bw=0 at :7390), [min∓3h] otherwise; d=(b−a)/(bins−1); d not >0 (all data equal) → Ok(None) quietly (giac divides by 0).
- Index trunc((x−a)/d+1/2) exact on rationals, f64 of balls otherwise; L exact on exact h,d. Convolution direct over nonzero counts, symmetric weights (C0084).
- Piecewise built as Piecewise[x<g0,0,…,x<=g_last,…,0], breakpoints Real (exact on exact grid), evaluated.
