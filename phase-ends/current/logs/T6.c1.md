## Decisions where §4 silent
- Rule lhs with a head lowering refuses (Planned, `i`, syntax form, value builtin like `pi`, non-Name callee, non-application non-operator lhs): treated as up-rule (Rule scope; `::`-tagged names and spreads params, other names uses). Every non-assignment Definition is a Rule scope.
- Up-rule params include spreads `xs...` too (lowering's Literal mode makes them pattern variables), not only `::`-tagged.
- Assignment / `local` / `for` / `Fill` target defines whatever its key resolves to at that spot: param assigned in a block → definition of the param (lowering reports AssignedParameter); top-level `local`/`for` → globals.
- Fill binding only for a statement-level `Fill(v, A)` with exactly two args, `A` a Name (any ExprStmt, top level or block).
- Parameter `Definition.node` = the ArgList child holding the name (`n = 1`, `xs...`, `n :: t`, `g(x)` for `f(g(x))`); up-rule param node = the Typed/Spread; lambda param node = the name.
- Definition lhs = first child ending before `:=` token.
- Locals created eagerly per block (from `assigned_names`), so a junk local from a nameless `for` can be a symbol with no occurrences.
- Reserved symbol name = `spelling(target)` else key; Type symbol name = `type_spelling` else key.
