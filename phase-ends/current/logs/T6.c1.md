## Decisions
- is_irreducible via `FactorList` (`factors`), which works over ℚ whatever with_sqrt (probe: `factors(x^2-2)` whole, `factor(x^2-2)` split). Constant/0 → count 0 → 1.
- factor_xn: `Times[x^n, Plus[...]]` stays unexpanded (probe: `x^3*(1+x^-1)` evaluates to itself); no Hold needed.
- homogenize counts every non-numeric symbol (`Expr::is_numeric` excludes Pi etc.).
- rootof variable: the single non-numeric symbol of the non-list args (x if none); two → Ok(None).
- Expert correction (applied): det/resultant unit test. det(B) is ±lc(f)^(deg f−deg g)·Res, not ±Res: for (5x³−x, 3x²+1) det=320, Res=64 → row `Det = 5·Resultant`; (x³−2x+1, x²−1) has Res=0 so replaced by (x³+1, x³+x): det = Res = −2, and (x²+1, x+2): det = −Res = −5.
- `rootof(x+2,x^2-2)`, `rootof(...)^2`, `homogeneize(x^2+x+1/2)` agree with giac (poly1 reads back as a list) → agreement rows, not departures.
- libgiac caseval prints `undef` for `rootof([1,0])` (CLI: `infinity`); table records `undef`.
- Side note: giac's `det(bezoutian(5x^3-x,3x^2+1))` prints -320 though the matrices agree and the hand determinant is 320; not used in any row.
