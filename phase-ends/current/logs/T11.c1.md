# T11.c1 — CAS-441: Fourier table rules only for a real pole/jump

## Cause (verified by reading)
- `with_factor` PV branch `1/(p x + q)` (fourier_transform.rs, `// 1/(p x + q), the principal value`) checked only `Re B = 0`, never that `−q/p` is real.
- Fuzz `Sg==`: inverse transforms `F = 3/2 e^(−2(−1−i s))/(−1−i s)` in s: `p = −i`, `q = −1`, `q/p = −i` → PV fired → `3/4 e^(−x) sign(−2−x)`.
- Siblings with the same assumption: θ/sign/UnitBox branch (jump at `−q/p`), UnitBox and `two_sided` (`|p|` as real scale).

## Change
- `crates/cas-core/src/native/fourier_transform.rs`: new `real(ev, b)` (`Im b` evaluates to 0); PV needs `real(q/p)`; θ/sign/box branch needs `real(q/p)`; box also `real(p)`; `two_sided` needs `real(p) && real(q)`. Otherwise `Ok(None)` → stays. Doc header notes the condition.
- Symbolic `p`/`q` (`Im[a]` not 0) now stay; no existing test uses symbolic shifts (all numeric, tests.rs read).
- `tests.rs`: `complex_poles_are_not_principal_values`: the fuzz inverse and `FourierTransform[1/(x − I), x, s]`; each must contain no `Sign` and either stay or agree with the true value (`f` at x = −3, 3/7, 5/2; `2πi e^s θ(−s)` at s = 3/7, 5/2, −4/3). By reading, both stay (rational route is P/Q over ℚ only; the exp factor and complex coefficients exclude it). Not run locally (CI only).
