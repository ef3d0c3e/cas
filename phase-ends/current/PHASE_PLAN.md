## Risks
- A push during T10 cancels the campaign (fuzz.yml:36-38). The router or Claude pushing a docs commit mid-campaign costs about four hours: T10's summary/log commits stay local, and nobody pushes until T10 is done.
- The campaign's 56 jobs queue behind the account's concurrent-job cap; CI runs from other pushes would queue with them. Detect: jobs `queued` for long; the wait is just longer, not a failure.
- Fuzz corpora grow over an hour per target; the actions cache (10 GB per repo, LRU) may evict older corpora. Detect: a target restoring an empty corpus on a later run; nothing to fix this phase.
- A one-hour target can find slowness in old code (C0052-C0055); the generation plan's split threshold is at 12 tasks: more findings than T11 can fix become a reopened T11.1, and Claude splits through ## Changes if T11 reopens twice.
- Random sweeps draw different inputs on every CI run (proptest's default RNG): a finding may surface on a later, unrelated push. The shrunk input persists to .proptest-regressions; it is fixed in the task that sees it, or in T11.
- CI's oracle installs libgiac0t64 from debian:sid unpinned: a giac upgrade changes answers in untouched tests. Detect: oracle failures outside the task's files or a version other than the one in README; record it, fix rows or departures in T11.
- The gap buckets in R1.8-003 are a hand tally; T2 re-tallies with a script. If C grows past ~60, T3-T6 may outgrow one task each: reopen as T<n>.1 rather than widen.
- New builtin names collide with symbols in use (range, back, shift, order, root, roots, lower, upper, has, format, period, basis, choice, lin): a new builtin can capture a symbol an existing test or the fuzz corpus uses. Detect: check_round_trip, every_builtin_is_named_or_internal and failures in untouched tests; each build task greps en.txt, lowering and test suites first (C0008).
- Adding builtins renumbers symbols and moves bloom-filter bits; a `!e.may_contain(S)` assert in an untouched module can flip (C0058).
- The local stable clippy (1.99.1) is older than CI's (R80): CI may flag what the local gate passed; fix it in the task.
