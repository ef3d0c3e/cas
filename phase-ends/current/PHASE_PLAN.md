## Rationale
- Ten tasks: the design page, six build tasks, the push and CI-check pair, the cleanup. Area 14 is 50 names, but 46 are option words: the work is in their meanings (giac's branch and bound, nlpsolve's integer variables) and in four ports, so no split.
- Build tasks follow code areas, not families, so one expert reads one part of the code: lpsolve's surface (lpsolve.rs, the names), its branch and bound (integer.rs, simplex.rs), nlpsolve (nlpsolve.rs), the tableau (simplex_reduce beside simplex.rs, with the CoefficientList check), univariate and polytope minimisation (minimax.rs's cover and golden search, the compiled evaluation), simulated annealing (user functions, the seeded generator). lpsolve's options come first: the milestone's core and the most names; its branch and bound next, on the surface T2 leaves; then nlpsolve, which reads T3 for its integer variables; the four commands last, simulated_annealing at the end: it has no precedent (a native applying the user's functions, R1.5-003), and if the phase must split, it moves whole. They run in sequence: all edit en.txt and builtin.rs, T5-T7 also native.rs and BUILTINS, and each pushes master.
- Every build task pushes and waits for CI (R16 and the developer's brief): tests run only on CI and the rows are written without a local run, so the expert who wrote the code fixes a failure while it holds the context. Build tasks do not wait for Fuzz (40 minutes, cancelled by the next push); T8 pushes the final head and T9 waits for both, 1.3's and 1.4's shape.
- lpsolve's options split in two (T2, T3): the surface (names, forms, mixed integer lists, lp_method, decimal data) is a parsing change over the existing solver; the branch and bound is a port of giac's lpsolve.cc:1599-1931 with its strategies, cuts, heuristic and limits. giac's defaults become ours (best local bound, pseudocost branching, 5 cut rounds, the heuristic on), so node, depth and gap limits stop near where giac's stop; giac breaks node ties at random (lpsolve.cc:1741-1745) and ours by a fixed rule, which is why rows compare the optimum by value and the point by feasibility.
- Limits stay deterministic: the engine keeps no clock and the evaluator's limits have no time field (R1.5-003), so lp_timelimit is accepted and bounds nothing ours can measure; the evaluator's limits and the host's interrupt (context.rs:570) bound the work, as the generation plan says ("through the evaluator's limits"). Where giac's clock changes its answer (lp_timelimit=1 gives [] on the nonnegint row), a departure row. Node, depth, iteration and gap limits keep giac's meaning: the incumbent, or giac's [] when there is none, each with a warning that names the limit where giac says "no feasible solutions".
- nlpsolve: giac 2.0.0.21's nlpsolve fails on every inequality-constrained and integer problem probed, its own aide examples included ("Failed to find a solution", probe2, probe4; CAS-519 found the same), so those rows test known optima and record giac's error; where giac answers (bounds, equations, no constraints, initial points, and the precision, tolerance, method and maximize options) rows compare within giac's error (C0006). Ours keeps its one certified method: nlp_method's values are accepted and run it, as 1.4's six system solvers all run our certified Newton. A bounded integer box is enumerated exactly (giac's differential evolution is random and fails here): exact answers where the objective is exact (R67); unbounded integer variables go through branch and bound on certified relaxations, local as giac's.
- find_minimum claims a global minimum on [a,b]: ours certifies it with minimax's error cover (1.4/T7) and encloses the minimiser. frank_wolfe's stop claims a Frank–Wolfe gap below tol: ours certifies that gap in ball arithmetic. simulated_annealing ports GSL's loop as it is (siman.c:53-179), our seeded generator in place of GSL's, and is tested against the known optimum.
- CoefficientList: R1.5-003 found its leading-first order is giac's symb2poly order and its doc's (polytools.rs:28-29, :359), so 1.4/T7's "exchanged terms" may be that convention read backwards; one unit test with ball coefficients settles it on CI in T5, fixed there if it fails. Cheap, so folded in (the brief).
- No `effort: high`: giac's numbers, known optima, enumeration and the same-optimum tests arbitrate every done-when.
