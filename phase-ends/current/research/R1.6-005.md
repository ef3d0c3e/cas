### id numbering (probe1.out:42)
- Ids are assigned by `++idc` at tag creation, post-order: children first, parent last.
- `export_mathml(a+2*b)`: a=id1, 2=id2, b=id3, times-apply=id4, plus-apply=id5 (content ids).
- Presentation side uses `xref='idN'` on the same nodes (e.g. `<mi xref='id1'>a</mi>`).
- Default mode: one shared `idc` counter, one `gen2markup` pass for both.

### entities used (probe4.out)
- `&it;` implicit times between factors (`<mo>&it;</mo>`). `&minus;` unary and binary minus. `&af;` function application (sin, cos, f(x), ln). `&middot;` (binomial). `&times;` (scientific 1.5e-7). `&geq;` and `&gt;` (order relations, probe4 :99-100 shows x<y printed as y&gt;x). `&infin;`, `&pi;`, `&alpha;`, `&theta;`, `&lfloor;`/`&rfloor;`.
