emd is a double-precision sifting loop over GSL splines: natural cubic (gsl_interp_cspline) when a envelope has >2 knots, otherwise linear. Endpoints 0 and n-1 are always knots of both envelopes. Bit-exact output needs GSL's cspline.c and tridiagonal solver, which are outside this repo scope and were not read. Sanity check on the sample: residue = x - imf1 holds (2-0.508370535714=1.491629464286; 3-0.978794642857=2.021205357143).

Spline: knots at integer x positions, strictly increasing. len>2 -> natural cubic (second derivative 0 at both ends); len==2 -> linear. No extrapolation (knots span 0..n-1). Eval uses GSL accel (no numeric effect).

Stop rules:
- Sift stops after iteration k when var_k <= vtol AND |zc_k - ne_k| <= 1, with zc/ne from pre-sift h_k.
- IMF extraction stops when ne < emin (checked at top of each sift iteration, before envelopes). Residue = h at that point; if not the first sift of the round, residue is partly sifted h, not x (5198-5199).
- imax: outer loop only, `==` test after each push (5204). Default RAND_MAX makes it effectively unbounded; termination comes from ne<emin.
- The inner sift loop has no iteration cap, only convergence. vtol=0 (accepted by _emd, 5241) can loop forever.

Cost: one sift = O(n): extrema scan, two spline builds O(k) (tridiagonal solve), two evals over n points, mean, var. No O(n^2) step. Total = (#sifts) * O(n); #sifts unbounded a priori.

Worked check, sample [1,2,1,3,1,2,1,3,1]: interior maxima at 1,3,5 and minima at 2,4,6, so ne=6, zc=0, notimf true. Endpoint values 1 and 1 are knots, so imf[0] and imf[8] are 0 up to rounding (the -2.77e-17 in the sample). Remaining imf values need the cspline coefficients, not verified.
