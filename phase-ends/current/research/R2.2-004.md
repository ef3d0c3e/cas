## Answer

- Lowering is one pass: `lower(&Parse, &Names) -> Lowered` (lower.rs:281). Statements with a syntax error are skipped before lowering (lower.rs:292-302). Lowering errors drop only their own statement (`failed`, lower.rs:303-311).
- Bindings and scope rules are interleaved with Expr construction (every fn returns `Lowering = (Expr, Spans)`, lower.rs:321). Only AST-level helpers are reusable as-is: `assigned_names` (lower.rs:1943), `name_of` (:1798), `target`/`syntax_form` (:463-479), `setting` (:484), `has_statements` (:1998).
- Scope rule to mirror: a block's locals are the names its statements assign, minus reserved names and minus parameters in scope (lower.rs:1447-1452). Parameters are NOT renamed; a body name lowers to the same user symbol as a global (lower.rs:824). Only assignment is refused (lower.rs:579).
- Only two diagnostics carry a fix: `FunctionWithoutParentheses` (lower.rs:996, fix :992) and `PowerOfFunction` (lower.rs:1010, fix :1003-1009, None if no exponent text). All other diagnostics carry `None`.
- Fix and Diagnostic are public: re-exported at lib.rs:53; `session::Message` carries `fix: Option<Fix>` (session.rs:163), copied from lowering at session.rs:285.
