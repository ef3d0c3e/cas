- The crate-level `#![allow(clippy::cast_*, reason = "...")]` at crates/cas-tune/src/main.rs:27-32 is the existing pattern for pedantic casts in a binary.
- Implications for a new binary crate:
  - `unreachable_pub` (warn) fires on `pub` items in a bin crate, since nothing outside can reach them. Use `pub(crate)` or private items.
  - `missing_debug_implementations` only checks types reachable from outside, so it rarely fires in a bin. Deriving Debug anyway is the habit the workspace follows elsewhere; this is reasoning from rustc's lint scope, not verified by a build.
  - `unsafe_code` is denied, so a bin cannot use unsafe without a crate-level override that the lint would reject.
  - Clippy pedantic plus `-D warnings` in the clippy job means pedantic warnings fail CI.
- fuzz/ is outside the workspace: fuzz/Cargo.toml:21-23 declares its own `[workspace] members = ["."]`. The root `crates/*` glob does not include it. Its profile is `[profile.release] debug = 1` (fuzz/Cargo.toml:25-26). It depends on cas-core, cas-lang, cas-num and cas-poly by path, plus `rug`, `arbitrary` and `libfuzzer-sys`.
