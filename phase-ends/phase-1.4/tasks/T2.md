Decisions:
- Rules as exact rational (t, w) on [0,1], node a + t(b−a) in ball arithmetic at working precision + 32; Romberg R(n,n) by Richardson on the level sums (ball or expression), not on exact weight vectors (cost at n = 16).
- Exact path only when compile/bounds fail and f, a or b hold a non-numeric symbol other than x; otherwise an uncompilable integrand stays unevaluated.
- gauss15 calls `nintegrate` directly (its Ok(None) passes through), any n ≥ 0; never giac's (estimate, error) pair.
- n: rationals floored, decimals floored via to_f64; n = 0 → Indeterminate (trapezoid, simpson, with a warning), 0 (rectangles), one panel (Romberg); n < 0 unevaluated; node count (n, n+1, 2n+1, 2^(n+1)+n; Romberg n < 62 before the shift) ≤ min(MAX_EVALUATIONS, limits().terms) before any evaluation.
- `area` visibility: `pub(in crate::native)` (pub(super) in a nested module is not reachable from native.rs).
