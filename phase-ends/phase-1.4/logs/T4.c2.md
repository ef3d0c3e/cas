# T4.c2 — CAS-594: ratinterp, triginterp

## Changed
- `crates/cas-core/src/native/interpolation/interpolants.rs` (new; declared in interpolation.rs, doc cross-ref): `rational_interpolation`, `trigonometric_interpolation`; module doc cites optimization.cc `_ratinterp`/`_triginterp`.
  - ratinterp: own arg parse (first arg a matrix ⇒ 2-col matrix form, opts at 1; else X,Y lists, opts at 2; ≤ 2 opts); n+1 ∈ 2..=MAX_POINTS; d default n/2+1, explicit d ∈ 0..=n (d = n+1 = giac's undef ⇒ stays); bound (n+1)(d+1)² ≤ 2^16 (`MAX_RATIONAL_WORK`); weights in `Rational` when all X rational, else Expr with `vanishes` (exact 0 or ball mid 0.0 via to_f64/total_cmp) ⇒ Ok(None); r = Together[Σ w y/(t−X) / Σ w/(t−X)], t = x0 if symbol else `x`; list x0 ⇒ Together of substitution per point; other x0 ⇒ Together of substitution.
  - triginterp: `(ys, x==a..b)` (Equation|Equal, Range) or `(ys, a, b, x)`, x a symbol; n ∈ 2..=MAX_POINTS, n·⌊n/2⌋ ≤ 2^13 (`MAX_TRIG_TERMS`); b−a vanishing ⇒ stays (giac undef); exact Cos/Sin at evaluated angles; ball in ys/a/b ⇒ `N` of result.
