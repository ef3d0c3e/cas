## Fix (crates/cas-num/src/complex/ring.rs)
1. Integer-only rounding: `q = round(Re/Im(a b̄) / N(b))`, halves away from zero (= `Rational::round`), via new `round(n, d)`. 16000 bits: 0.46 s. Fuzz replay timeout unit still 22.8 s (full-size products a b̄, N(b) per step, Toom-3 in gdb).
2. `leading_quotient`: when `bits(b) > 128` and `bits(a) <= bits(b) + 32`, quotient from leading 64 bits of b (parts truncated by 2^k), fixed point 40 bits; error < 2^-28 (bound in doc comment); falls back to exact path when a fractional part is within 2^-20 of 1/2 → q bit-identical to exact rounding. Step cost = product by small q. 16000 bits: 64 ms; 64000 bits 0.87 s.
- Verified: 20000 random pairs (100–500 bits, gap 0–50, ¼ constructed near-half) `div_rem` == exact-rational rounding (scratch `.run/1.4/t9/c6/bench`). Unit outputs unchanged vs before.
