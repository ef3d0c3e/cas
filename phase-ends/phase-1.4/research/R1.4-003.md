## Answer

- bspline: exact symbolic de Boor over an padded knot vector; knots default linspace(0,1,nt) with nt=nc-p+1; output one [Re,Im] polynomial pair per piece. Exact rationals.
- fitspline: least-squares cubic (default p=3) B-spline fit (gsl_multifit_linear), NOT smoothing; knots uniform on [min s, max s] unless breakpoint= given; outputs doubles.
- minimax: Remez exchange on [n,m] rational form; returns [best_err, p/q]; double arithmetic throughout; rand= uses giac global RNG.
- fitpoly: expression path = Chebyshev-coefficient adaptive degree up to maxdeg (default 15); data path = windowed degree search with tol default 0.01; no-variable result is a poly1[...] object (highest degree first), hence poly1[1,0,1.0] = x^2+1.0.
- ratinterp: Floater–Hormann barycentric, exact rational arithmetic; default d=floor(n/2+1), n=|X|-1.
- triginterp: exact DFT-style trig interpolant, N=floor(n/2) harmonics, period T=(b-a)*n/(n-1); evalf only if inputs approximate.
- numdiff: Sadiq & Viswanath (2014) FDWeights (Fornberg branch compiled out by #if 1); exact on exact data; uses all N+1 points.
- tpsolve: NWC initial basic feasible solution + MODI; big-M is 1/eps (not a simplex big-M); returns [cost, X] with first-found optimal basis.
