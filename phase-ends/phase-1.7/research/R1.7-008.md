## Findings
- Quality/converter claims (quality.html): all three sinc converters 97 dB SNR; BW 97% (best), 90% (medium), 80% (fastest). ZOH/linear: "not bandlimited, and the user is responsible for adding anti-aliasing filtering."
- src_sinc.c (secondary extraction) comments: fastest "97dB SNR, 80% BW", medium "121dB SNR, 90% BW", best "144dB SNR, 96% BW". These conflict with quality.html (97 dB for all). Treat as unresolved.
- Table headers: best `make_src_filter(cycles=69, incr=2381, atten=160)`, stopband 154.67 dB, -3dB width 1.922, half length 340238. Medium `make_src_filter(cycles=21, incr=491, atten=122)`, stopband 120.61 dB, -3dB width 1.811, half length 22437. Fastest `make_filter(8, 128, 100.3)`, stopband 100.71 dB, -3dB width 0.484, half length 2463. -3dB width units are not stated.
- src_sinc.c: coeff_half_len = ARRAY_LEN(table.coeffs) - 2; index_inc = table.increment; linear interpolation between table entries; float_increment = index_inc * min(src_ratio, 1.0) (kernel widens when downsampling); input_index += 1/src_ratio.
- src_sinc.c buffer: history zeroed at reset (zero-padded start); at end, if in_used == in_count and data->end_of_input, memset of half_filter_chan_len+5 zeros (clamped), b_real_end set. Input frames used = in_used/channels.
- src_linear.c: input_index += 1/src_ratio; seeded from first frame after reset; stops when in_used + channels*input_index >= in_count; saves last_position and last frame for next call; no padding, no end_of_input handling.
- src_zoh.c: same stepping; output = held frame; loop condition uses "<=" on in_count; last consumed frame held for next call.
- src_simple (samplerate.c): sets end_of_input = 1 ("Only one buffer worth of input."); no output-length formula. Output length (if any) is the caller's choice; docs give none.
- Latency: not documented in fetched pages. Sinc history starts zero-filled; no explicit delay term seen in fetched excerpts. Unverified.
- Smith (ccrma resample index): ideal lowpass windowed by a Kaiser window (method citing Rabiner & Gold); table stores L samples per zero-crossing, L=2^n_l, with difference table for linear interpolation; N_z zero-crossings trade aliasing vs bandwidth. Smith's pages do not give libsamplerate's specific numbers.
- Generation evidence: headers contain only the make_filter/make_src_filter call line (cycles, incr, atten) and results. Inference: "atten" is a Kaiser-style attenuation target, and "incr" is the table oversampling factor (table entries per zero-crossing, Smith's L). Window and cutoff not stated. The tests/ directory has no generator (only test programs such as snr_bw_test.c).
- License: COPYING is BSD-2-Clause text (Copyright (c) 2012-2016 Erik de Castro Lopo); src files carry 2002-2021 headers. Pre-2016 was GPL or commercial (license.html).
