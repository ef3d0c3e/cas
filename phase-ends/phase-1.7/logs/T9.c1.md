## Decisions
- giac messages kept as warnings for every stay: "Unsupported wavelet type", "Wavelet not implemented", "Invalid argument k", "Data must be numeric", "Failed to convert data to GSL matrix", "Failed to allocate memory" (member left invalid by a later string: `"haar","daubechies"`).
- Padding warning before the numeric check (giac's order); size check (padded n or n², times nc; nc=1 when the member is invalid) before any warning, silent Ok(None).
- `image` on a list ignored (giac). Matrix = non-empty list of non-empty equal rows (ckmatrix); a ragged list is 1-D → "Data must be numeric".
- A bare `bspline` symbol (BSpline builtin) is "Invalid argument" like giac's bare `haar`.
