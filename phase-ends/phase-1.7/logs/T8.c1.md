## Decisions
- giac generic type/dim errors (arity, odd mixdown count, parm list > 5, splice exact non-integer overlap e.g. 3/2 or sqrt(2)) stay silently (C0042).
- Sizes: mixdown len*channels and splice (pos+len_b)*channels <= Limits::terms else "Too many samples"; offsets/fades in seconds saturate (f64 -> i64 `as`), integers saturate.
- splice SAME check after the position check (giac's order: "Invalid splice position" first).
- std::pow(x,2) in mix's fades written x*x (gcc folds it); other pow -> powf (libm).
- set_channel_data's 5th argument accepted and ignored (giac's).

## Findings
- generalizable: giac's splice with a second clip shorter than the overlap computes a result of len_a-n+len_b samples but memcpys len_a-len_b samples of a into it (heap overflow, :1203-1204); the visible answer is the truncated copy (probe1:56-58). Port with bounded copies.
- generalizable: a silent or negatively correlated overlap gives similarity NaN, exponent NaN, so every crossfade sample is NaN -> code 0 except the last ((i+1)/n = 1, pow(1, NaN) = 1) (probe1:36-39).
- generalizable: giac's mix/splice clipping flag is overwritten per sample: only the last sample's status reaches the warning.
- is_audio_position accepts 0.0 (is_positive(0.0) true) (probe1:1).
