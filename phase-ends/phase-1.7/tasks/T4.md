Summary: Xcas's Markov chain commands now exist. markov finds the closed classes, their long-run probabilities, the passing states and the chance of ending in each class, listed in the same order as giac. It solves for these numbers exactly instead of iterating, so exact input gets exact answers (1/2 where giac prints a 13-digit fraction), and chains where giac's loop never ends still get an answer. randmarkov walks a chain or builds a random one through the seeded generator.

Decisions:
- Class search and order are giac's: stochastic by rows, else by columns (transposed); edge iff entry nonzero; Tarjan from state 0, successors ascending, classes in stack-pop order; recurrent = no edge leaves the class.
- Numbers by linear solves through matrix.rs inverse_of: π(P_C−I)=0 with Σπ=1, absorption (I−Q)⁻¹R; exact on exact input, balls when any entry is decimal; eps accepted (any real) and unused.
- Row sums: exact rows sum to exactly 1; decimal rows within 1e-12 in f64.
- randmarkov draws exact rational rows exactly and decimal rows in f64; randmarkov(v, nt) entries are decimals as in giac.
