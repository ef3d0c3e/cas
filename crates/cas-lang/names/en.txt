# English surface names, the base of every locale (CAS-DOC-7 §5).
#
# Format, shared with locale overlays:
# - `#` starts a comment, and blank lines are ignored.
# - `[section]` starts a section.
# - `Target: name name …` gives the names of a target. The first name is the
#   spelling printers use; the others are aliases. A name is one identifier of
#   the language, in Unicode normal form C, and not a keyword.
#
# Sections:
# - [builtins]: builtins of cas-core, by internal name.
# - [planned]: builtins the design pages name that cas-core does not define
#   yet. Their names are reserved now. An entry moves to [builtins] when its
#   builtin is added; a test fails until it does.
# - [constants]: `imaginary`, the imaginary unit.
# - [syntax]: forms that lowering and the session handle: `call`, `assume`,
#   `purge`.
# - [types]: the types written after `::`, in a namespace of their own.
# - [internal]: builtins without a surface name, each reached through syntax
#   or not at all. Every builtin is in [builtins] or here; a test checks it.
#
# A locale overlay may use [builtins] (for any builtin named in this file,
# planned or not), [constants], [syntax] and [types]. Its first name for a
# target becomes that target's spelling in the locale, and the English names
# stay valid. Names follow Xcas where Xcas has one.
